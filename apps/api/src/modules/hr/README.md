# HR Module

人事模块目录：考勤、绩效、人工薪资台账、工资应付与工资支付。

员工档案本身挂在生产模块的主数据端点（`production/employees`，见
`apps/api/src/modules/production/production-master-data.service.ts`），信息口径 = 《在职员工花名册》导入模板：

- 花名册列（28 列）中除 5 个公式派生列外全部落库，派生列（年龄/工龄/当月生日员工/合同即将到期人员/
  劳务合同即将到期人员）由后端按当天日期实时计算；
- 工号可留空，按 `EMP-当天日期-序号` 自动生成；
- 身份证号码反推出生日期与性别，并校验校验位；
- 导入解析按表头名匹配，手工维护的花名册（标题行 + 两级合并表头 + 末尾批注）可直接上传。

完整口径、解析规则与已知缺口见 `docs/design/employee-roster-import-2026-09-16.md`。
