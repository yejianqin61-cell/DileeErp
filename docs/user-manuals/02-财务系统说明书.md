# 财务系统说明书

**适用角色：财务（`caiwu`）**  
**页面范围：**全部页面。岗位主责是财务确认、收付款、银行、凭证、报表与财务复核；进入业务页面是为了核对来源和处理协作，不等于代替销售、采购、仓库、生产或人事录入。

> **权限注意：**当前“财务”是页面可见范围，不是后端的业务职责隔离。请按本说明书的岗位分工执行，并让来源岗位和复核人保留各自动作证据。

## 财务工作总链

`原料入库 / 外加工签收 → 应付来源 → 确认应付 → 付款、核销、冲销 → 收支流水 / 凭证`  
`成品出库 → 应收来源 → 确认应收 → 收款、核销、冲销 → 收支流水 / 凭证`

每个箭头都应按订单号、来源单号、单位、币种、金额和状态复核。**确认挂账不等于资金到账；过账付款/收款才会影响银行余额。**

## 通用财务规范

- 金额不跨币种相加；涉及外币时核对币种、汇率日期和折人民币结果。
- 先查询来源单和未核销余额，再建立收付款草稿；禁止为了凑平金额新建无来源单据。
- 已过账事实只允许冲销、红冲、更正或按页面受控流程处理；不得直接改写。
- 银行账户为余额变动的必要依据。没有正确银行账户时，停止过账。
- 确认、付款、收款、冲销和对账均需与业务责任人及银行/回单交叉核对。

## 应收、收款与对账

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 需要配合与核对 |
| --- | --- | --- | --- |
| 查看应收来源 | 从“财务”进入“应收管理”→按订单号、客户、状态筛选→打开来源详情→核对成品出库、客户、数量、单价、币种和未确认余额。 | 应收来源来自成品出库；先确认出库已真实发生，不能凭销售单或计划数直接挂应收。 | 销售和仓库提供出库及签收依据。 |
| 确认或取消应收 | 目标来源→查看影响预览→选择款项性质（定金/货款/尾款/其他）→确认→复查状态和生成的挂账；误确认按“取消”或后续受控调整处理。 | 确认应收是权责挂账，生成草稿凭证，不是到账；取消前检查是否已有收款、对账或下游凭证。 | 销售确认合同/价格，仓库确认出库，客户回款信息由财务核实。 |
| 建收款草稿并核销 | 收款区“新建”→选择客户、币种、收款日期、银行账户和金额→选择一笔或多笔有效应收→逐行填本次核销金额→保存草稿→复核总额。 | 分批、多次核销可用；逐行核销金额是唯一真源，不能超过可核销余额。客户与币种必须匹配。 | 出纳核对银行回单；销售核对客户与订单归属。 |
| 收款过账或冲销 | 草稿核对无误→过账→复查应收状态、收支流水、银行余额和凭证；错误已过账收款走冲销。 | 过账才销账并变更银行余额；冲销必须引用原事实，不能静默删除。 | 出纳提供回单，财务复核人核对金额、日期和账户。 |
| 应收调整、红字、退款、折扣、坏账 | 目标应收→先看影响预览→按业务类型新建调整/红字/退款/折扣/坏账→录入原因和金额→保存/确认→核对余额与审计。 | 此链路标记为待完整验收；生产使用前要按真实场景完成验收。不得以普通收款代替退款或坏账。 | 销售/老板确认商业原因；出纳与会计复核资金和会计口径。 |
| 应收对账与收款单 | 在对账/单据工作区选已核实记录→按客户和币种组织→确认/导出收款单→按银行回单逐项复核。 | 一张单据只能对应一个收款单位和币种；客户主数据暂无正式银行信息，收款单对方账户需财务按回单填写。 | 客户回单、销售对账资料、出纳银行流水。 |

## 应付、付款与供应商对账

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 需要配合与核对 |
| --- | --- | --- | --- |
| 查看应付来源 | 从“财务”进入“应付管理”→按订单、供应商、状态筛选→打开详情→核对原料入库或外加工签收来源、数量、单价、币种和余额。 | 实际付款只认入库或签收金额；采购计划金额不是付款金额的替代来源。 | 采购核对供应商和单价，仓库或外协核对入库或签收数量。 |
| 确认或取消应付 | 在“应付管理”查看来源及影响预览→确认应付→复查挂账及订单摘要；错误且无下游时按取消处理。 | 确认应付是挂账，不是付款；有已付款、已对账或下游凭证时不得绕过限制取消。 | 采购、仓库或外协提供来源核对。 |
| 新建或导入其他应付 | 从“应付管理”进入“其他应付”→先查重→手工填写或下载模板导入→核对科目、供应商、日期、币种、金额和说明→保存。 | 只用于非订单支出；草稿和已确认其他应付可逻辑删除，但已被付款核销或对账覆盖的不能删。原料入库和外加工来源形成的应付不能当“其他应付”删除。 | 经办人提供原始单据，老板或会计确认支出性质与科目。 |
| 单笔付款 | 付款区新建草稿→选供应商、币种、付款银行、日期→选应付并填核销额→保存→核对→过账。 | 不得超过应付余额；必须选择银行账户，过账会扣银行余额并写收支流水。 | 出纳核对付款回单；采购确认付款对象和应付来源。 |
| 合并付款 | “确认应付”页勾选应付→以第一条为锚点→只选择同一供应商、同一币种记录→逐行填核销金额→建付款草稿→过账。 | 系统锁定不同供应商/币种；金额以逐行核销额为准，表头总额只读派生；付款银行账户必填。 | 采购/经办人核对每张来源单，出纳核对合并付款回单。 |
| 集中付款与付款单导出 | 在集中付款工作区选多笔待付款→系统按供应商+币种自动拆分成单据队列→逐张修订、导出或全部导出→逐张确认。 | 跨供应商或币种不会合成一张单；导出前才要求编号、双方单位和借贷平衡满足要求。供应商结算信息无法识别时，对方银行信息留空后人工补。 | 出纳、供应商对账单、采购负责人。 |
| 付款过账、冲销和对账 | 付款草稿逐项核对→过账→检查应付状态、银行余额、收支流水与凭证；错账走冲销，再按真实记录重建。 | 付款过账才影响余额；不允许删除或覆盖历史付款事实。 | 出纳回单、供应商对账、会计复核。 |

## 银行、现金流、科目、凭证和财务报表

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 需要配合与核对 |
| --- | --- | --- | --- |
| 维护银行账户与查看余额 | 从“财务”进入“银行账户”→查询账户→新建、编辑或停用→核对期初、余额、币种与用途。 | 银行余额由已过账收付款、转账及受控流水变化；账户信息需按开户资料维护。系统暂无联行号字段，跨行转账单需手填。 | 出纳提供银行资料，老板或财务负责人复核。 |
| 银行互转 | 从“财务”进入“银行互转”→新建→选择付款和收款账户、日期、币种、汇率、金额和用途→保存、过账→复核两端余额。 | 转出与转入账户不可混淆；外币折算与金额大写必须一致。 | 出纳核对银行流水；复核人检查双边金额。 |
| 导出或打印跨行转账单 | 打开目标互转记录→打开“跨行转账单”→补联行号等系统未保存字段→浏览器打印或存 PDF，或导出 XLSX。 | 该纸质件不落库，导出只留审计；金额大写留空时系统计算，手填必须与系统计算一致。 | 出纳按银行规则核对。 |
| 查看和维护现金流 | 从“财务”进入“现金流”→按日期、科目、类型筛选→查看来源→对错误流水按其来源走更正或冲销。 | 收支流水由确认、收付款过账等动作产生，不能以直接编辑掩盖来源错误。 | 与应收、应付、工资、出纳来源责任人核对。 |
| 会计科目与类目 | 从“财务”进入“会计科目”→先查询→维护科目或类目→保存→抽样检查分类和引用。 | 分类必须来自类目清单；资产、负债、成本、所有者权益、损益五个内置类目只读，改名会使三大报表失真。删除类目仅限没有科目。 | 会计负责人确定科目口径；业务经办人不得自行改变会计分类。 |
| 期初余额、期末汇率 | 科目页的“建账期初余额”“期末汇率”面板→选择期间/币种/科目→录入→保存→生成报表前核对差异提示。 | 报表以期初余额加建账后已过账凭证计算；缺汇率不会静默忽略，会列入报表尾部提示。 | 会计负责人/老板确认建账与期末汇率来源。 |
| 新建、编辑、过账、红冲凭证 | 从“财务”进入“记账凭证”→从流水生成或点“新建凭证”→填写日期、币种、摘要、借贷分录→保存草稿→核对借贷平衡和科目→过账；错账红冲。 | 手工凭证可用于折旧、摊销、工资计提、成本结转等无现金来源业务；草稿可编辑，过账后只能红冲。导出前必须满足借贷平衡。 | 会计编制，复核人审核；相关业务人提供原始凭证。 |
| 导出三大报表及业务财务报表 | 从“财务”进入“财务报表”→选择资产负债表、利润表、现金流量表或其他报表→选期间→先预览差异和表尾提示→导出 XLSX。 | 三大报表只取已过账凭证；未生成凭证流水、草稿、未归位科目、缺汇率、期初差额会列提示。核算表和毛利表仅含已出货销售单，部分出货按整单计入并须留意表尾。 | 老板或会计负责人审阅，销售与仓库确认出货口径。 |

## 薪资、业务来源、协作查询和账户

| 动作 | 页面与步骤 | 规则与协作 |
| --- | --- | --- |
| 财务复核薪资并付款 | 从“人事”查看已确认工资台账→核对社保、个税、工资支付科目和应付→进入“工资支付”建草稿、分批核销、过账或冲销→回台账核对状态。 | 社保、个税由财务逐行填写，不自动计算；生产计件和计时来源仍待完整验收。与人事、生产负责人共同复核。 |
| 核对业务上游 | 从“工作台”、客户与销售、采购、质检、仓库、生产进入，按订单号打开来源单→比对状态、数量、单位、单价、币种和审计记录。 | 财务发现来源错误时退回给责任岗位更正，不在财务端虚构抵消单。 |
| 报表与告警 | 从“报表与告警”进入→筛选订单、期间、状态→查看订单、采购应付、库存、生产质检、薪资报表及告警→把异常派发给责任人。 | 报表是查询和复核，不替代来源单事实；采购与仓储报表不跨单位相加、库存为物料级当前结存且无合计行。 |
| 账号管理 | 从侧边栏“账号中心”进入→可创建账号、重置他人密码、启用或停用、改角色；操作后要求对方重新登录确认。 | 这是表面权限配置，不是岗位审批；不共用账号，停用离职或调岗账户要先核实业务交接。 |
| 迪礼顾问 | 从侧边栏“迪礼顾问”进入→提出明确只读问题→查看来源→回原单或报表复核。 | 财务可访问财务档位数据，但顾问不能写账、过账或替代会计复核。 |

## 每日/每月复核

1. 每日：查看待确认应收应付、待过账收付款、银行余额异常、付款/收款失败和告警。
2. 每周：与采购核对应付来源，与销售/仓库核对应收来源和已出货口径，与人事核对工资变动。
3. 月结前：核对所有未核销余额、期初余额、期末汇率、未过账凭证、报表尾部缺口及三大报表勾稽项。
