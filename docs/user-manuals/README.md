## 使用口径

- 本套说明书以当前代码、页面路由及 `docs/product/module-capability-catalog.md` 为准，编写日期为 **2026-11-09**。
- 「页面权限」是前端菜单和页面门禁。当前后端的业务模块权限对这四类角色均授予全部业务模块；因此，岗位分工、复核和审批要求必须由管理制度执行，不能只依赖“看不到菜单”。
- 单据删除默认是**软删除**；已经过账、确认、支付或存在下游事实的记录，必须依该单据提供的更正、冲销、退回或恢复流程处理，不能以新单覆盖旧事实。
- 「待完整验收」表示已有页面或接口，但真实业务数据、异常路径或权限场景尚未完成最终验收；说明书不会把它表述为已通过完整生产验收。

## 共同操作规范

1. 先按订单号、单据号、日期和状态查询，确认没有可复用或待处理的记录，再新建。
2. 保存草稿只保存当前输入；**确认、过账、关闭、冲销**会改变上下游状态，应先核对数量、金额、单位、币种、日期、关联订单和附件。
3. 出现影响预览、超量、库存不足、待补价、下游已存在、告警或不一致提示时，停止“强行继续”，先按提示处理或与责任岗位复核。
4. 每一次更正、改号、冲销、删除或例外下单都应填写真实、可追溯的原因；不得用空泛文字代替原因。
5. 单位、币种、物料、订单号、供应商、客户等主数据是链路键值。未经相关责任人复核，不得为了“让单据能保存”而临时替换。
6. 通过账号中心改密码后妥善保管；离岗应退出登录。发现账号不应再使用时，通知老板或财务停用。

## 当前 V1.0 明确边界

- 不支持询盘、报价、样品单、英文合同、自动排产、自动采购建议、订单级库存预留、库位/批次成本、复杂审批、税费社保自动算薪、总账、税务申报和银行自动对账。
- 采购退货、外加工现场生产日报、成品 QC 的完整复检/返工/报废闭环、订单关闭前检查等能力仍需按页面状态与实际验收结果确认。
- 迪礼顾问只能在当前数据权限内**只读查询**，不能创建、修改、确认、过账或替代人工复核。
