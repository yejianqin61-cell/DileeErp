# 系统说明书

**适用角色：其他（`qita`）**  
**页面范围：**工作台、迪礼顾问、生产、采购、质检、仓库、客户与销售、返单与总结、报表与告警、账号中心；不能进入财务与人事页面。

> **权限注意：**页面限制只决定前端可见范围；当前后端并未以这四个表面角色隔离业务接口。因此，财务、人事和跨岗位复核事项必须由账号、流程和管理制度共同约束。

## 职责边界

“其他”是普通业务操作的页面角色，不是单一岗位。实际使用时应由管理者明确此账号是销售、采购、仓库、质检、生产、外协还是管理查询人员。下列动作按业务责任分组；只办理本人岗位被分配的动作。财务确认/收付款与人事档案/薪资不得通过借用账号办理。

## 所有业务的共同步骤

1. 从工作台或对应模块按订单号/单据号/状态找到记录；先看详情、审计和关联单据。
2. 在草稿中录入可验证资料，保存后重新打开核对。
3. 需要确认、下单、到货、过账、关闭、冲销或删除时，先处理页面提示的影响预览、数量、库存、价格、币种、下游单据和告警。
4. 动作完成后在来源单、下游单或工作台确认状态已改变；把待办交给下一责任岗位。

## 销售与客户

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 配合与核对 |
| --- | --- | --- | --- |
| 维护客户与联系人 | 从“客户与销售”进入“客户池”→先搜索客户代码或名称→新建或编辑→维护联系人→保存→复查状态。 | 客户名称和客户代码应唯一；已被单据引用的客户不要直接删除，按停用或恢复管理。联系人快照会进入销售单。 | 销售与客户确认主数据；财务如需结算信息另行核对。 |
| 新建销售单 | 从“客户与销售”进入“销售单”，点“新建销售单”→选择客户和联系人→填写唯一订单号、日期、产品、规格、数量、单位、交期、币种、价格、金额及扩展资料→保存草稿→详情复核。 | 一张销售单对应一款产品；有效订单号唯一。金额、数量、单位、币种和交期要与客户订单一致。 | 销售主管或客户资料责任人核对合同、客户采购订单、价格和交期。 |
| 编辑、确认、关闭销售单 | 打开订单→草稿中编辑→保存；满足必填条件后点确认；全部业务完成后按状态关闭。 | 状态只允许受控推进。已确认单改核心字段、回退草稿会检查 BOM 和下游；系统可自动清理“0 明细、无计划、无采购单、无生产单”的空壳 BOM，其他下游仍会阻止。 | 改核心资料先与采购、生产、仓库、财务核对影响。 |
| 改订单号 | 编辑订单号→先读影响预览→填写必填原因→确认全链更新→按旧/新号分别抽查关联单据和审计。 | 任何阶段均可改号，但会事务更新全链冗余订单号；客户不可换头。并发冲突需重新查询后再试。 | 通知采购、生产、仓库、质检、财务及跟单人员使用新号。 |
| 删除草稿销售单 | 仅草稿行点删除→确认列表移除；需要复用号时重新建单。 | 仅 `draft` 且没有下游事实可删，软删并释放订单号；下游存在会拒绝并列出阻塞类型。 | 先和已接单的采购/生产人员确认未启动。 |
| 导入、复制及导出工艺单 | 销售单导入页下载模板/上传并处理行错误；需要复用时按复制入口新建后复核；工艺单导出时选物料图片并生成 XLSX。 | 导入错误按行处理；工艺单材料引用、图片、细分明细及“其它”行需保存后生效。每个位置最多 3 张图片。 | 销售与生产共同核对生产单图片、材料、工艺要求和版本。 |
| 建立、维护、发布或删除 BOM | 从“采购”进入“BOM表”，或从销售单详情进入→从已确认销售单建 BOM→维护物料、规格、供应商、参考单价→保存或发布；删除前看预览→按要求填写原因。 | BOM 不会随销售单后续核心变更自动改写；参考单价仅预填采购计划，不参加金额计算。空 BOM 可直接删；有明细或计划要填原因；被未取消采购单或未删除生产单引用会拒绝。 | 销售确认需求版本；采购确认物料、供应商和参考价；生产确认可制造性。 |

## 采购、来料与原料仓库

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 配合与核对 |
| --- | --- | --- | --- |
| 维护单位、物料、供应商与图片 | 从“采购”进入“物料清单”“供应商”等基础资料页→先查询→新建、编辑或停用→保存→核对审计。物料批量导入按模板处理；图片上传、换图或删除。 | 单位不自动从导入创建；导入只新增不修改，逐行报错。物料图片为 WebP，单张≤2MB、边长≤2000。 | 采购、仓库、生产统一物料、单位和供应商口径。 |
| 新建采购计划并填价 | 从“采购”进入“采购计划”→从 BOM 创建计划→核对自动带入的明细、供应商、数量和单位→在“填单价”逐行填单价或导入 BOM 参考价→保存计划。 | 一个销售单的一份 BOM 一份计划；行总价等于数量乘单价，只读派生；金额不跨币种相加。未下单且单价为 0 的行才可导入参考价。 | 采购向供应商核价；销售和生产确认补料原因和数量。 |
| 价格待定下单 | 计划中选 0 价行→收束下单→认真阅读确认框→确认价格待定→保存并跟踪补价。 | 普通下单禁止 0 价；价格待定是例外，**到货登记前必须补价**，防止形成 0 元应付。 | 采购跟进供应商报价；财务知悉未确定金额。 |
| 按供应商收束下单 | 在计划勾选行→按供应商分组→选择各组币种→预览→确认下单→到采购单列表核对生成记录。 | 一供应商一张采购单；未勾选行仍留计划，可多波次下单；供应商地址/联系人为只读派生。BOM外补料/替代料必须填新增原因。 | 采购负责人核对供应商、价格、交期；财务后续按入库金额付款。 |
| 改计划、退回采购计划 | 未下单行在计划编辑；已下单且无到货事实的采购单可退回采购计划→核对计划行恢复。 | 采购单明细只读，数量/单价/供应商在计划改；退回不清数量/单价/供应商，作废单留痕。有到货事实不能退回。 | 与供应商、仓库确认没有到货。 |
| 登记分批到货与来料质检 | 从“采购”进入“到货管理”→选择采购单和明细→录入实到数量、日期等→保存；再从“质检”进入“来料质检”创建或录入检验→填写合格、条件接收、不合格→复查累计。 | 关闭采购单后不可到货；到货及质检草稿不改变库存。质检累计不得超过到货数量；单价为 0 的采购明细不可登记到货。 | 仓库核对实收，质检核对检验数量和结论，采购处理供应商异常。 |
| 原料入库、过账、冲销 | 来料 QC 合格/条件接收后→建立原料入库草稿→核对可入库数量、物料、单位、批次来源→过账→在原料库存查事实；错误走冲销。 | 仅 QC 合格/条件接收数量可入库；过账才改变库存并生成应付来源。草稿、QC、到货不改变库存。 | 仓库执行，质检确认合格量，财务据入库应付来源挂账。 |
| 原料领料、退料、报废 | 从“生产”进入“领料管理”→选生产单和物料→录入领用、实发、补料等数量→保存草稿→查看影响预览→过账；退料、报废同样走受控单据；错单冲销。 | 库存由事实聚合，禁止负库存；不能直接改余额。领料、退料、报废及反向事实都保留审计。可导出或打印领料单、补料单。 | 生产确认需求和实耗，仓库确认实发，质检或主管确认报废，财务关注成本和应付影响。 |

## 生产、外协、成品质检与成品仓库

| 业务动作 | 页面与步骤 | 规则、限制与操作规范 | 配合与核对 |
| --- | --- | --- | --- |
| 维护生产主数据 | 从“生产”进入“工序池”“生产地点”“生产单元”等基础资料页→查询→新建、编辑或停用→保存。 | 工序稳定后优先停用而非删除；计件和计时单价与方式需按真实制度维护。 | 生产负责人确认；人事和财务使用员工和计薪口径时同步。 |
| 创建、编辑、删除生产单 | 从“生产”进入“生产单”→从销售单或 BOM 创建，或按授权人工新增、拆分→选择厂内或外加工、地点、工序及目标数量→保存→详情核对；草稿可按规则软删。 | 默认一订单一生产单，扩展或拆分必须保留订单关联；状态推进与关闭会检查工序、数量和告警。 | 销售确认订单版本，采购和仓库确认物料，生产负责人批准计划。 |
| 登记工序日报与员工日报 | 生产单详情→选工序与生产日期→登记工序日产量；按员工分别登记计件或计时日报→保存→检查累计和告警。 | 同一员工、同日、同工序允许多条记录；计件不强制时长，计时不强制件数（件数不计薪）。日报变更会影响薪资来源。 | 班组长/生产负责人核对产量；人事/财务复核工资来源。 |
| 处理生产进度与告警 | 生产页/报表与告警→按订单、工序、日期查进度→处理工序超单或工序日报与员工日报差异→修正来源记录并留原因。 | 不要用改汇总数“消告警”；先确认是哪一种来源和日期造成差异。 | 班组长、员工、人事共同复核。 |
| 外加工物流 | 外加工生产单→登记原料直发、批次、外加工点签收→登记余料回厂、成品回厂或成品直装柜→核对状态和数量。 | 外加工现场生产日报不进入 V1.0 ERP；直装柜/回厂数量必须与来源和签收一致。 | 外协点、仓库、质检、销售共同交接；财务据外加工签收形成应付。 |
| 成品送检与质检 | 从“质检”进入“成品质检”→从跨订单待检列表或订单详情进入→选择送检批次→录入合格、不合格、特殊标记→保存→核对已检和待检累计。 | 待检列表只含“待质检”和“质检中”，按送检日期排序；数量由系统累计。复检、返工、报废完整闭环待完整验收。 | 生产送检，质检判定，仓库仅按合格或条件接收数量入库。 |
| 成品入库、出库与退货 | 从“仓库”进入“成品仓储情况”，或从“客户与销售”进入“成品出库总览”→以质检合格品建入库草稿→分批过账；出库时选销售单、填发货和签收资料→过账；退货按退货入库或冲销流程。 | 成品库存由入出库事实决定；出库须有库存和销售单价，过账才生成应收来源。错误走冲销，不能修改已过账库存。 | 质检确认合格量，仓库确认数量与签收，销售确认客户和价格，财务确认应收来源。 |

## 跨模块查询、返单、报表、账号

| 动作 | 页面与步骤 | 规则与配合 |
| --- | --- | --- |
| 查看订单全链 | 从“工作台”进入→按订单号搜索→打开详情→依次核对销售单、BOM、采购到货、来料质检、原料库存、生产、成品质检、库存、发货、应收应付及审计。 | 工作台用于找阻塞和交接；来源记录仍以各业务单据为准。跨模块异常交给对应责任岗位。 |
| 返单与总结 | 从“返单与总结”进入→按货号查询历次批次→查看销售、采购、生产、质检、仓库和财务关联摘要→用于复盘和返单前核对。 | 返单分析是只读汇总；新订单、BOM、价格和库存仍需按各模块正式创建。 | 销售发起，采购、生产、仓库核对历史可复用信息。 |
| 报表与告警 | 从“报表与告警”进入→选订单、日期、状态或物料→查看订单、采购应付、库存、生产质检、薪资及采购仓储报表→导出或打印前抽样核对；告警进入详情、处理并备注。 | 报表不跨单位错误相加；采购仓储报表库存是物料级当前结存，不按订单分账且无合计行。告警处理须改正事实或说明原因。 | 报表责任人和来源岗位共同复核。 |
| 迪礼顾问 | 从侧边栏“迪礼顾问”进入→描述明确问题→看来源→回到业务单据复核。 | 只读、受数据档位限制，不能写单或过账；不可代替库存、数量、交期或质量的现场核验。 |
| 自助账户 | 从侧边栏“账号中心”进入→改本人姓名或密码、查看权限范围、退出。 | 不可管理其他账号；新建、改角色、停用需求交老板或财务。 |
