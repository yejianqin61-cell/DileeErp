# 老板系统说明书

**适用角色：老板（`laoban`）**  
**页面范围：**全部页面。老板角色适合经营总览、例外审批、跨角色复核和账号管理；日常录入应保留给对应岗位，避免由管理账号承担销售、采购、仓库、质检、生产、财务与人事的同一链路操作。

## 先理解权限边界

老板和财务在当前系统中可见全部页面。菜单可见性不是审批工作流，也不是后端职责隔离；系统没有用这四个表面角色阻止老板直接提交业务接口。因此，本说明书把需要第二人复核的动作明确列出，建议实际管理中由不同账号完成录入和复核。

## 老板的日常经营巡检

| 巡检目标 | 页面与步骤 | 必看口径 | 处理与配合 |
| --- | --- | --- | --- |
| 看订单全链与阻塞 | 从左侧菜单进入“工作台”→按订单号搜索→打开详情→顺序查看销售单和 BOM、采购到货和来料质检、原料库存、生产日报、成品质检和出库、应收应付及审计时间线。 | 订单号是全链业务身份证；看状态、数量、单位、币种、告警和下游阻塞，不只看一个“完成”标签。 | 将阻塞明确交给销售、采购、质检、仓库、生产或财务，并要求在来源单处理。 |
| 看风险和报表 | 从“报表与告警”进入→选期间、订单、状态或物料→查看订单、采购应付、库存、生产质检、薪资和采购仓储报表→打开告警。 | 采购仓储报表不跨单位相加，库存为物料级当前结存，不按订单拆账；核算和毛利报表只含已出货销售单。 | 报表发现问题回溯来源，不用汇总页直接“调平”。 |
| 看返单历史 | 从“返单与总结”进入→按货号查询历次订单和关联单据→比较产品、物料、供应商、质量和进度。 | 返单页是只读总结，不能替代新订单、BOM或采购计划。 | 销售、采购、生产共同确认新批次是否沿用历史。 |
| 看财务经营事实 | 从“财务”进入“财务报表”等工作区→查看应收应付余额、银行余额、现金流、已过账凭证和三大报表→阅读表尾差异提示。 | 确认应收和应付为挂账；收付款过账才影响银行余额。三大报表只取已过账凭证，未过账、缺汇率、期初差额会列提示。 | 财务提供对账与凭证证据；老板决定重大折扣、坏账、超预算或异常资金处理。 |
| 看人员与薪资状态 | 从“人事”进入→看在职和离职、合同提醒、考勤绩效、薪资台账和支付状态。 | 人事资料和工资为敏感信息，按最小必要范围查看；薪资确认与实际支付不是同一状态。 | 人事核对人员事实，财务核对社保和个税、付款和凭证。 |

## 经营决策涉及的业务动作

| 动作 | 页面与步骤 | 规则、限制与复核 |
| --- | --- | --- |
| 决定接单、改核心订单或改号 | 从“客户与销售”进入“销售单”→打开销售单与影响预览→核对客户、价格、数量、币种、交期及下游单据→批准责任岗位保存或确认；改号必须填原因并核查全链结果。 | 已确认订单改核心字段会受 BOM 和下游事实限制；系统只会自动清理无明细且无下游的空壳 BOM。改号会事务更新全链，但必须通知所有执行岗位。销售、采购、生产、仓库、财务共同复核影响。 |
| 决定物料、BOM和采购例外 | 从“采购”进入“BOM表”或“采购计划”→核对 BOM、供应商、参考价、计划数量和交期→批准补料或替代料原因、价格待定下单→跟踪补价。 | 价格待定只是一项受控例外，到货前必须补价；采购单明细不可在采购单页直接改，应回采购计划修改。采购、生产和财务共同确认成本与可制造性。 |
| 决定生产和外协安排 | 从“生产”进入→核对订单和 BOM、厂内或外加工、工序、目标数量、地点和物料准备→批准拆分、扩展或重大变更→跟踪日报、超单和差异告警。 | 不以口头产量替代日报；同一员工同日同工序可有多条日报，薪资来源须与人事和财务复核。外加工现场日报不进入系统。生产负责人主办，仓库、质检、采购和人事配合。 |
| 放行质量和发货例外 | 分别从“质检”和“仓库”进入→查看来料和成品质检、数量与特殊标记→仅按合格或条件接收数批准入库→在出库前核对库存、销售单价、发货和签收资料。 | 到货和质检草稿不改变库存；入库和出库过账才形成库存事实。库存不足、质检不合格或无销售单价时不放行。质检、仓库、销售与财务双重核对。 |
| 决定资金例外 | 从“财务”进入“应收管理”“应付管理”、付款、收款或银行工作区→看来源、影响预览、余额、银行账户、币种和回单→批准折扣、退款、坏账、其他应付、合并付款或大额互转→要求财务过账。 | 已过账记录必须冲销或红冲，不能删除覆盖；付款和收款逐行核销金额不能超过余额，银行账户必填。财务主办，业务经办人与出纳提供来源和回单。 |
| 决定人事例外 | 从“人事”进入→看档案、合同、考勤绩效、薪资调整与离职信息→批准政策性或重大调整。 | 社保和个税当前由财务按实际数填写，并不自动计算。员工逻辑删除保留历史，恢复前核对身份与业务交接。人事主办，财务复核资金。 |

## 账号、权限和审计管理

| 动作 | 页面与步骤 | 限制、规范与复核 |
| --- | --- | --- |
| 新建账号 | 从侧边栏“账号中心”进入→账号管理区“新建账号”→填写用户名、姓名、初始密码和一个表面角色→创建→通知用户首次登录并改密码。 | 不开放自助注册；角色决定页面范围：老板和财务全页，人事仅人事、账号中心和顾问，其他除财务人事外的业务页、账号中心和顾问。创建前核实岗位和离职替换关系。 |
| 改角色、重置密码、启用/停用 | 账号行→“改角色”/“重置密码”/“停用或启用”→确认对象和影响→操作→要求对方重新登录验证。 | 不停用自己；角色变化与停用在下一次请求生效。账号生命周期需有人员/部门负责人复核，不用共享账号代替临时授权。 |
| 看审计与异常 | 在各列表详情、工作台、报表与告警中查看创建人、更新人、时间、状态和操作理由→按单号回溯。 | 软删除、冲销、更正、改号和例外下单都应留下审计；发现无理由或跨职责操作，保留证据并调查，不直接删记录。 |

## 老板的业务链检查清单

| 链路阶段 | 最低检查 | 主责任 | 老板应确认的交接 |
| --- | --- | --- | --- |
| 客户→销售单→BOM | 客户、订单号、数量、价格、交期、版本、BOM物料完整 | 销售/采购 | 销售确认后采购与生产是否拿到正确版本。 |
| BOM→采购计划→采购单→到货→来料QC→原料入库 | 供应商、单价、币种、到货量、合格量、入库量和应付来源可追溯 | 采购/质检/仓库 | 0价不应到货；QC合格量不应被超入库；财务应付只据入库/签收。 |
| 原料→生产→工序日报→成品QC→成品入库 | 库存不负、领退废可追溯、目标与日报累计、超单/差异告警、合格量 | 仓库/生产/质检 | 人事/财务拿到可核对的薪资来源；不合格成品不混入合格库存。 |
| 成品出库→应收→收款 | 可用库存、销售单价、发货/签收、应收来源、逐笔核销和银行回单 | 仓库/销售/财务 | 出库与资金状态分别确认；收款过账后余额、流水和凭证一致。 |
| 入库/外协→应付→付款 | 入库或签收来源、供应商、币种、余额、付款账户和回单 | 采购/仓库/财务 | 合并付款只同供应商同币种；过账后应付、银行和凭证一致。 |

## 老板不应绕过的系统规则

1. 不能直接编辑库存余额、已过账收付款、已过账凭证或历史工资事实；使用冲销、红冲或受控更正。
2. 不能以口头批准绕过唯一订单号、库存不足、数量上限、QC上限、0价到货门禁、借贷平衡或银行账户必填。
3. 不能把迪礼顾问当作执行工具。它只能只读查询，重要结论必须回到来源单据、现场记录和银行回单复核。
4. 不能把全页面可见性视为自己应录入全流程。经营复核要保留责任岗位和第二人核对证据。
