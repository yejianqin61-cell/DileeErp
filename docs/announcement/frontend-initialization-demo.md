# 前端初始化演示公报

## 当前可演示内容

- 统一 ERP 工作台布局和桌面导航。
- 工作台：订单推进、生产工序进度、应收应付三个讨论视角。
- 生产、采购、财务、仓库、人事、客户池六个模块占位页面。
- 演示数据提示、空状态、加载状态、错误状态和公共列表结构。

## 当前不可视为最终规格

- 模块字段、状态、筛选条件和主操作。
- 生产工序、库存成本、批次、单位换算、财务形成节点和人事字段。
- 真实业务数据、真实 API 和数据库写入。

## 访谈方式

请各模块负责人以实际日常工作为依据，确认首屏入口、需要比较的信息、主操作、状态变化和异常场景。反馈应回写到术语词典、模块说明和对应任务文档。
