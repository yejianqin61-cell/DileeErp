# Agent 交接文件夹

本目录用于**跨会话交接**：每个会话（或每个大批次）结束时写一份 `<日期>-<主题>.md`，
让下一位 agent 不读历史对话也能接手。

约定：

- 一份文档 = 一次会话/一批交付；文件名 `YYYY-MM-DD-<slug>.md`。
- **不要复制已经在别处存在的内容**（提交信息、diff、设计文档、任务书）：用
  `提交 hash`、`文件:行`、`docs/...` 路径引用即可。
- 必须写清四件事：①已交付什么（含验证方式与数字）②现在卡在哪/什么是红的
  ③下一步按优先级该做什么 ④环境约束与坑（含并发的其他写者）。
- 交接文档只描述状态与下一步，不改代码；代码事实以 git 历史为准。
