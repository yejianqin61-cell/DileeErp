# 文档工作区

| 目录 | 用途 |
| --- | --- |
| `product/` | 项目总览、PRD、SRS、术语词典和模块边界 |
| `design/` | 技术设计、架构决策和开发计划 |
| `task/` | 可由 Agent 认领和执行的子任务 |
| `test/` | 测试策略、测试记录和验收证据 |
| `announcement/` | 开发公报、评估报告和对外/对内通知 |
| `log/` | 每日开发日志，文件名使用 `YYYY-MM-DD.md` |
| `memo/` | 尚未确认的业务事项和访谈备忘 |

所有决策遵循 [Agent Constitution](../.agent/constitution/constitution.md) 的可追溯性要求。
