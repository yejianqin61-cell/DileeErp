## 已验证的业务规则

- 销售单仅草稿状态可确认；确认后创建 BOM 必须继承销售订单的 `order_no` 与版本来源。
- 未确认销售单不可创建 BOM；空 BOM 不可发布；已发布 BOM 不可原地编辑。
- 来料 QC 累计送检量不得超过到货量，QC 分流量受校验。
- 原料入库量不得超过 QC 允许量；过账在单一事务内生成库存事实和应付来源，并拒绝重复过账。
