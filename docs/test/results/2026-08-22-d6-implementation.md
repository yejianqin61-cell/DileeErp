# D6 外加工直发链路实施结果

## 已完成

- 任务 01：外加工物流批次领域模型、迁移、草稿 API。
- 任务 02：直发、分批签收、短收提示和外加工应付来源候选。
- 任务 03：影响预览、签收冲销、直发取消、应付候选作废和审计。
- 任务 04：余料回厂待 QC 来源。
- 任务 05：成品回厂待 QC 来源。
- 任务 06：成品直装柜来源、发出和冲销。
- 任务 07：生产页外加工交接工作流。
- 任务 08：本结果报告与 D6 质量门禁。

## 已验证

- `npm run typecheck`：通过。
- `npm run test:unit`：通过，包含 D6 直发签收数量边界和不入厂内库存不变量。
- `npm run build --workspace=@dilee/api`：通过。
- `npm run build --workspace=@dilee/web`：通过。
- Prisma schema validate/generate：通过。

## 待环境具备后验证

- 独立 PostgreSQL 迁移与 D6 事务回归。
- 真实 API HTTP 契约和认证/RBAC 回归。
- Playwright 登录、批次、直发、签收、回厂和直装柜主旅程。

## 边界确认

- 外加工现场生产日报、工序、员工薪资和加工费不进入 ERP。
- 直发与签收不创建厂内原料库存事实；签收只提供外加工应付来源候选。
- 余料/成品回厂在 QC/入库前不改变库存；直装柜不改变厂内成品库存。
- E1-E5 后续消费成品回厂和直装柜来源，财务确认/付款仍由后续链路实现。
