# 0821-05-03 生产退料与报废

## 状态

已完成

## 目标

让车间将已领但未使用的原料退回可用库存，或将无法使用的原料登记为报废，从而同时保证库存余额、车间持有量和生产消耗事实自洽。

## 范围

- 在统一原料流转模型中交付退料和报废草稿、过账、列表、详情及生产单领料可处分数量查询；
- 退料和报废明细必须关联同一生产单下的原领料明细；按原领料、已退料、已报废及有效状态计算可处分数量；
- 退料过账写入可用原料库存的正向事实，报废只写入不可删除的报废/持有量事实，不回补可用原料库存；
- 支持多明细、分批操作、原因与审计，拒绝跨生产单来源、超过可处分数量和无效生产单；
- 为后续冲销提供稳定的来源关系和数量快照。

## 非范围

- 冲销已过账领料、退料或报废；
- 不良品库存处置、供应商退货、盘点和外加工余料；
- 工序日报、员工薪资或成品完工数量。

## 验收与验证

1. 退料数量不得超过原领料在既有退料和报废后仍可退的数量，成功退料准确回补可用原料库存。
2. 报废数量不得超过车间实际持有数量，成功报废不增加可用原料库存且可按订单、生产单和物料追溯。
3. 同一原领料支持多次退料与报废，服务端在并发请求下保持数量约束和库存一致性。
4. API 拒绝外加工、暂停/完成/关闭生产单以及跨生产单原领料引用；所有拒绝使用统一错误契约。
5. 真实 PostgreSQL 和 API 测试覆盖退料、报废、超量、库存影响和审计结果。
