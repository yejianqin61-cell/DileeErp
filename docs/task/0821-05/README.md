# 0821-05 原料领料、退料、报废与库存联动链路任务

本目录交付 D4：`厂内生产单 -> 原料领料 -> 生产退料/报废 -> 原料库存事实与告警`。既有链路已经提供认证、RBAC、审计、统一 REST JSON 契约、已确认销售订单、已发布 BOM、厂内生产单，以及采购来料 QC 后的可用原料库存；本批复用这些能力，不重建采购入库或生产单基础模型。

实施前阅读 [原料领料、退料、报废与库存联动链路实现设计](../../design/raw-material-issue-return-scrap-inventory-chain-implementation-design.md)、[仓库模块初步设计](../../design/warehouse-module-design.md) 与 [全局 API 与错误处理契约](../../design/global-api-contract.md)。每项完成时必须更新该任务状态、每日开发日志、编码路线图和测试证据。

## 依赖顺序

```text
01 通用库存事实扩展与入库回归
  -> 02 厂内生产原料领料与影响预览
  -> 03 厂内生产退料与报废
  -> 04 原料流转冲销、审计与附件
  -> 05 原料流转前端工作流
  -> 06 D4 API 与数据库回归
  -> 07 D4 浏览器验收与链路关闭
```

`05` 可在 `02` 后开始领料页面骨架，但只有 `04` 完成后才可交付完整工作流。`06` 依赖后端业务闭环，`07` 依赖全部前序任务。外加工物料直发、工序日报、薪资、成品 QC/入库及全局告警中心均不属于本批。
