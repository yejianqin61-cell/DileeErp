# 0821-05-05 原料流转前端工作流

## 状态

已完成

## 目标

让仓库、车间与物控操作员无需接口调试工具，即可在 Web UI 中完成厂内生产单领料、退料、报废、风险确认、冲销和历史追溯。

## 关联决策

- `raw-material-issue-return-scrap-inventory-chain-implementation-design.md` 的 4.4、4.5、4.6 节
- 前端统一 TanStack Table、shadcn/ui、React Hook Form 约束
- 编码路线图 D4

## 范围

- 在生产或仓库工作台接入真实 API 的原料流转列表、生产单上下文、领料/退料/报废表单、影响预览、过账、冲销、审计和附件入口；
- 表单始终显示 `order_no`、生产单号、厂内地点、物料、单位、库存影响及来源领料关系；
- 超领和非 BOM 物料显示风险与原因必填状态；库存不足、超出可处分数量、无权限和并发冲突显示 API 返回的可理解错误；
- 提供加载、空状态、未登录重定向和不可操作状态，不显示演示数据或伪造库存余额。

## 非范围

- 手机端、离线操作、通用告警中心和报表导出；
- 外加工物料直发、工序日报、薪资、成品库存页面；
- 绕过服务端校验的前端本地库存计算。

## 验收与验证

1. 有权限操作员可从生产中的厂内生产单进入领料，并在过账前看到真实库存/BOM/累计领料影响。
2. 操作员可对原领料选择退料或报废，页面只展示有效的来源与可处分数量。
3. 已过账单据的冲销入口展示影响与原因，成功后历史和余额实时更新；不可冲销原因清晰可见。
4. 列表支持按订单号、生产单号、物料、类型、状态和日期检索，且可下钻查看审计和附件。
5. Playwright 覆盖真实登录、领料、退料或报废及库存结果；前端类型检查与生产构建通过。
