# 0821-05-02 厂内生产原料领料与影响预览

## 状态

已完成

## 目标

让仓库操作员可针对生产中的厂内生产单创建分批原料领料草稿、预览物料风险并安全过账，使可用原料库存形成可追溯的负向事实。

- `warehouse-module-design.md` 的原料领料规则
- 编码路线图 D3、D4

## 范围

- 建立原料流转单头/明细的领料类型、草稿与过账状态，以及服务端生成的领料单号；
- 仅允许生产中的厂内生产单创建和过账领料；服务端从生产单解析 `order_no`、BOM 快照、地点和计划数量；
- 支持多物料、分批领料，过账前返回可用库存、BOM 参考量、累计净领料、拟领后余额及风险预览；
- 过账在一个事务中写入表单、负向库存事实、风险确认和审计，并以幂等键避免重复扣减；
- 库存不足为硬性门禁；超领或领用非 BOM 物料必须填写原因后允许过账；
- 提供受 RBAC 保护的领料草稿、预览、过账、列表和详情 API。

## 非范围

- 退料、报废、冲销和附件；
- 外加工单领料或采购直发外加工；
- 前端完整工作流与生产日报。

## 验收与验证

1. 已入库可用原料可被同一生产单分批领用，且每笔领料均可回查 `order_no`、生产单、物料、单位和操作人。
2. 库存不足时整张领料单过账失败，不产生部分库存事实；重复过账不重复扣减。
3. 超领和非 BOM 物料在填写原因后可过账并保留风险确认；缺少原因被服务端拒绝。
4. 草稿可编辑或逻辑删除，已过账领料不可直接修改或删除。
5. 独立 PostgreSQL 与 HTTP/API 测试覆盖主路径、负库存、生产单状态/执行方式限制和幂等性。
