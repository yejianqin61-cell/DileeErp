# 0821-06-03 员工计件/计时日报、计价与薪资来源 API

## 状态

待开发

## 目标

实现员工计件/计时日报和只读生产薪资参考来源，使车间工作量可按已确认口径进入后续薪资模块。

## 关联决策

- D5 设计 4.2、4.3、4.7 节
- 人事财务模块设计的生产薪资来源规则
- 编码路线图 D5、F2

## 范围

- 实现员工日报列表、详情、创建、编辑、逻辑删除、影响预览及按员工/订单/生产单/工序/日期筛选 API；
- 根据员工、工序、计薪方式和业务日期带入有效单价，保存计薪方式、单价和参考金额快照；
- 实现计件 `件数 × 单价` 与计时 `分钟 × 单价` 的定点计算；计时件数仅进入核对，不进入金额；
- 提供按员工、日期范围/工资周期和计薪方式汇总的只读生产薪资来源查询。

## 非范围

- 月度薪资台账、财务调整、工资支付、考勤绩效和最终实发工资；
- 在生产模块中直接修改基础计价历史。

## 验收与验证

1. 有效在职员工和有效计价可创建计件、计时日报；停用/离职员工、无有效计价、非法件数或时长被拒绝。
2. 计件与计时参考金额符合口径；未来调价不改变既有日报快照；覆盖单价没有原因被拒绝。
3. 同一员工同日同生产单同工序支持多条有效日报并可正确汇总。
4. 人事/财务仅能读取生产薪资来源，不能通过 API 修改日报或来源金额。
