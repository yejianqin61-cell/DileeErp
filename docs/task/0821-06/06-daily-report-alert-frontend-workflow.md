# 0821-06-06 日报与告警前端工作流

## 状态

已完成（2026-08-22）

## 目标

让生产/物控操作员在 Web UI 完成厂内工序日报、员工计件/计时日报、影响预览、告警处理、进度查看和历史追溯，而无需接口调试工具。

## 关联决策

- D5 设计 4.4 至 4.8 节
- 既定 TanStack Table、shadcn/ui、React Hook Form 约束

## 范围

- 在生产工作台接入真实日报、进度、告警和薪资来源 API；
- 使用 React Hook Form 录入计件/计时日报，显式展示件数、分钟、单价、参考金额、订单号、生产单、工序和单位；
- 提供工序/员工日报历史筛选、影响预览、编辑/逻辑删除、附件入口和 API 错误提示；
- 展示超单、差异、待处理/确认/恢复告警，并支持填写备注后确认；
- 只展示服务端返回的累计量、金额和告警，不在前端自行计算业务结果。

## 非范围

- 手机端、离线、外加工日报、工资台账确认、成品 QC/入库和复杂报表导出；
- 绕过服务端校验的本地累计或薪资计算。

## 验收与验证

1. 登录操作员能完成工序日报和计件/计时员工日报录入，并看到真实进度、参考金额和告警。
2. 计时件数在界面显示为核对数据，金额按时长显示；超单/差异不阻止保存但清晰提示。
3. 编辑或删除前可看到真实影响预览，成功后历史、进度、告警和薪资来源刷新。
4. 未登录、越权、暂停/关闭单、无计价、非法数量和冲突均显示可理解的 API 错误。
5. Web typecheck、production build 和 Playwright D5 主旅程通过。

## 完成记录

- 在生产页面加入真实日报工作台：工序日报、员工计件/计时日报、历史、服务端进度和告警；
- 表单使用 React Hook Form，数量/分钟/单价/参考金额明确区分，计时件数标注为核对数据；
- 支持告警备注确认、日报影响预览后逻辑删除、幂等键提交和附件上传关联；
- 页面只展示 API 返回的累计、金额和告警，不在前端计算业务结果；
- 验证：`NODE_OPTIONS=--max-old-space-size=4096 npm run build --workspace=@dilee/web` 通过，Playwright 主旅程由 task 08 统一执行。
