# 0821-06 D5 生产日报、员工日报与告警链路任务

本目录交付 D5：`生产单/工序 -> 工序日报 -> 员工计件/计时日报 -> 差异与超单告警`。本批复用 D1-D4 已完成的员工、工序计价、厂内生产单、工序任务、原料流转、认证、RBAC、审计、附件、统一 REST JSON 契约及独立 PostgreSQL 测试基础设施。

实施前必须阅读 [D5 生产日报、员工计件/计时日报与差异告警链路实现设计](../../design/production-daily-report-payroll-alert-chain-implementation-design.md)、[生产模块初步设计](../../design/production-module-design.md)、[人事财务模块初步设计](../../design/hr-finance-module-design.md) 与 [全局 API 与错误处理契约](../../design/global-api-contract.md)。每项完成时必须更新任务状态、每日开发日志、编码路线图和测试证据。

## 依赖顺序

```text
01 日报、告警与薪资来源领域模型
  -> 02 工序日报与工序进度 API
  -> 03 员工计件/计时日报与薪资来源 API
  -> 04 日报差异/超单告警与审计
  -> 05 日报更正、影响预览与回退联动
  -> 06 日报与告警前端工作流
  -> 07 D5 API 与数据库回归
  -> 08 D5 浏览器验收与链路关闭
```

`06` 可在 `02` 后开始页面骨架，但必须等待 `05` 后才可交付完整纠错工作流。`07` 依赖后端闭环，`08` 依赖全部前序任务。外加工现场日报、成品 QC/库存、最终薪资台账、工资支付、自动排产和全局告警中心均不属于本批。
