# 0821-06-05 日报更正、影响预览、回退联动与附件

## 状态

待开发

## 目标

落实“进退皆可”：日报编辑、逻辑删除和附件说明均可受控执行，且完整联动工序进度、薪资来源和告警，不静默覆盖历史事实。

## 关联决策

- D5 设计 4.6、4.8 节
- 全局“可追溯更正”“影响预览”“attachment”规则

## 范围

- 为工序日报、员工日报的编辑/删除提供影响预览，展示累计量、差额、超单、差异、薪资参考和告警前后变化；
- 要求修改/删除理由并在事务内联动重算、审计和告警恢复/重新触发；
- 复用统一附件上传/关联能力，为日报保留凭证或说明入口；
- 落实幂等键、乐观并发/版本冲突和已关闭生产单的恢复后调整边界。

## 非范围

- 物理删除、直接改写审计、修改基础计价历史、最终薪资台账调整；
- 新建独立文件存储系统。

## 验收与验证

1. 影响预览与最终写入结果一致；成功操作后工序进度、薪资来源和告警都可由 API 读取验证。
2. 删除/修改日报不会物理删除原记录，均保留理由、执行人、时间和前后值审计。
3. 修改使异常消失时告警恢复；使异常出现时告警生成或复回待处理。
4. 幂等重试不重复写入；并发冲突返回 409；附件能关联日报实体。
