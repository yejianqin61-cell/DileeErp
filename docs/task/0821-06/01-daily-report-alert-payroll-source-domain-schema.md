# 0821-06-01 日报、告警与薪资来源领域模型

## 状态

已完成（2026-08-22）

## 目标

建立工序日报、员工日报、持续告警及只读生产薪资来源的数据边界和数据库迁移，使所有后续 D5 事实均能稳定追溯至 `order_no`、生产单、工序、员工和操作人。

## 关联决策

- D5 设计 4.1、4.2、4.3、4.5 节
- 编码路线图 D5、F2

## 范围

- 新增工序日报、员工日报、生产日报告警及生产薪资来源所需的 Prisma 模型、迁移、索引、外键和枚举；
- 落实 UUID、审计字段、逻辑删除、`order_no` 冗余追溯、业务日期、数量/时长/金额定点字段及备注；
- 约束告警以“生产单+工序+日期+类型”为持续业务键，历史通过状态和审计保留；
- 建立可复用的日报领域服务边界，禁止业务层手工维护累计进度、告警或薪资余额。

## 非范围

- 日报 REST API、前端页面、工资台账、工资支付和成品业务；
- 外加工现场日报、单位换算和自动排产。

## 验收与验证

1. 空测试库可应用迁移，所有新表均具有统一审计与逻辑删除字段。
2. 日报可追溯到订单号、生产单、工序任务、员工（适用时）和单价/金额快照。
3. 告警持续业务键、薪资来源只读关系和必要索引可支持后续事务重算。
4. 既有 D1-D4 schema、迁移和集成测试不回归。
