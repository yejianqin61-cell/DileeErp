# 0821-06-02 工序日报与工序进度 API

## 状态

已完成（2026-08-22）

## 目标

让操作员能对生产中的厂内生产单有效工序录入、查询和维护工序日报，并由服务端提供工序累计完成量、差额、超单量和状态。

## 关联决策

- D5 设计 4.2、4.4、4.7 节
- 编码路线图 D5、D7

## 范围

- 实现工序日报列表、详情、创建、编辑、逻辑删除、影响预览及按订单/生产单/工序/日期筛选 API；
- 服务端校验厂内、有效工序、生产单状态、正数量、业务日期和审计原因；
- 提供生产单工序进度查询：目标、有效累计、差额、超单量及自动计算状态；
- 在后续员工日报未实现前，为差异告警重算保留稳定的内部调用边界。

## 非范围

- 员工计件/计时日报、薪资金额、告警确认、前端和外加工日报；
- 手工编辑工序完成/超单状态。

## 验收与验证

1. 生产中的厂内生产单可新增多笔工序日报并正确累计；暂停、已关闭、外加工、取消工序和非法数量返回稳定 422 错误。
2. 累计小于/等于/大于目标分别返回进行中/完成/超单状态，超单不阻止保存。
3. 按订单号、生产单号、工序和日期查询结果可追溯；前端无需跨表汇总。
4. 创建、编辑、删除都保留操作原因和审计，且不物理删除历史事实。

## 完成记录

- 新增 `OperationDailyReportsService` 与 REST controller；
- 支持工序日报列表、详情、新增、修改、逻辑删除、影响预览和订单工序进度查询；
- 服务端校验厂内生产、有效工序、生产单状态、正十进制数量、非未来日期，并在日报变更事务内重算超单告警；
- 进度返回目标量、累计完成量、差额、超单量及 `in_progress`/`completed`/`over_order`/`cancelled` 状态；
- 验证：`npm run build --workspace=@dilee/api` 通过；真实 PostgreSQL API 回归统一由 task 07 执行。
