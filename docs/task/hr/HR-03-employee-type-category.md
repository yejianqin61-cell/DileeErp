# HR-03 员工类型类目

## 目标

把员工类型从人事页面硬编码选项改为可维护类目，并支持在新建/编辑员工表单中快速创建。

## 范围

- 复用 `DictionaryType` / `DictionaryItem`，新增固定字典类型 key（建议 `employee_type`）
- 字典初始化种子和人事页面读取/创建入口
- 不改变已有员工记录保存的字符串语义

## 实现要求

- 后端提供人事页面所需的员工类型列表和创建接口，限制为该字典类型。
- 初始化 `workshop`、`office`、`management` 三个已有选项，显示名称保持现状。
- 新建员工类型至少需要 key、名称；key 唯一，停用后不出现在新建下拉，但历史员工仍显示名称或 key。
- 新建、编辑员工表单都使用接口选项，并通过 HR-01 快速创建。
- 创建成功后回到原表单，保留其他员工字段并自动选中新类型。

## 验收

- 点击员工类型“新增类目”能打开创建表单，不再显示业务模块错误。
- 创建新类型后立即出现在当前员工表单并被选中。
- 刷新页面后新类型仍存在；停用类型不能用于新员工。
- API/Web 类型检查及字典服务测试通过。
