# HR-02 员工目录与筛选

## 目标

完善人事员工目录，展示完整任职时间，并支持日常筛选和离职状态操作。

## 范围

- `apps/web/app/hr/page.tsx`
- 现有员工 API 不足时才调整查询参数，不新增重复接口

## 实现要求

- 新建、编辑员工表单增加离职日期 `left_on`；保留现有入职日期 `hired_on`。
- 员工表增加入职日期、离职日期列，空值显示 `-`。
- 增加关键字筛选（工号、姓名）、状态、部门、岗位、员工类型筛选。
- 筛选条件可组合，清空后恢复全部员工。
- 离职操作沿用 `/production/employees/:id/leave`，成功后刷新状态和离职日期。
- 只对当前活动员工显示“离职”，已离职员工不能重复办理。

## 验收

- 新建员工填写离职日期后保存并在目录显示。
- 在职员工办理离职后状态变为离职且离职日期可见。
- 五类筛选条件均能准确过滤，组合条件不互相覆盖。
- Web 类型检查通过。
