# HR-05 人事流程员工快速创建

## 目标

让考勤、绩效、薪资台账中引用员工的下拉框都能快速新建员工，并可靠返回原业务表单。

## 前置依赖

- HR-01 共享新增类目返回链路
- HR-02 员工创建/编辑表单
- HR-03 员工类型类目

## 实现要求

- `employee_id` 的“新增类目”打开新建员工表单，而不是显示“请在生产基础资料中维护”。
- 创建员工成功后刷新员工选项，自动选中新员工；原绩效周期、评分、等级、考勤日期/时间、薪资周期等字段全部保留。
- 新建员工表单内的部门、岗位、员工类型继续支持嵌套快速创建，返回路径不能丢失。
- 考勤、绩效、薪资台账三处使用同一行为和错误处理。
- 员工创建失败或取消时，业务表单保持打开且输入不丢失。

## 验收

- 在登记绩效中创建员工并返回，提交绩效成功。
- 在登记考勤中创建员工并返回，提交上下班汇总成功。
- 在生成薪资台账中创建员工并返回，提交台账成功。
- 每个流程都验证原字段保留和新员工自动选中。
- 浏览器回归覆盖成功、失败、取消三种路径。
