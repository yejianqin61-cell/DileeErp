# HR-04 上下班汇总考勤

## 目标

将考勤定义为员工某工作日的一条上下班汇总记录，支持上班时间、下班时间，并保留已有日期和考勤类型语义。

## 数据约束

- 一条记录代表一个员工一个工作日的出勤汇总。
- `attendance_date` 为工作日期。
- `clock_in_time`、`clock_out_time` 为本地工作时间，格式 `HH:mm` 或数据库 `TIME`。
- 上班时间和下班时间均必填；下班时间必须晚于上班时间。跨午夜场景本任务不支持，后续另立任务。
- 员工离职前/入职前的日期按现有业务规则拒绝登记，需补充明确测试。

## 范围

- Prisma `AttendanceRecord` 模型和迁移
- HR controller DTO、service 校验、列表查询
- `apps/web/app/hr/page.tsx` 登记表单和列表
- 现有考勤测试与新增回归测试

## 实现要求

- 不把时间拼接进原 `DATE` 字段；增加明确的上下班时间字段。
- 调整同一员工同一天的唯一约束，避免重复汇总；更新接口支持修改上下班时间。
- 老数据迁移为兼容值：原日期保留，时间使用明确的空值/默认策略并记录迁移说明；不得伪造实际打卡时间。
- 页面使用组件库时间输入控件，列表显示“日期 / 上班 / 下班”。
- API 对格式、空值、下班早于上班进行可测试的 422 错误返回。

## 验收

- 可登记并刷新后仍看到日期、上班时间、下班时间。
- 无效格式、缺失时间、下班早于上班均被拒绝。
- 同一员工同一天不能创建第二条汇总记录。
- 编辑可以修改时间；已有日期数据不会丢失。
- API 类型检查、迁移验证、单元和集成测试通过。
