# E1 成品送检与 QC 核心对象、状态机与迁移

## 状态

已完成（2026-08-22）

## 目标

建立成品送检单和成品 QC 记录的可审计领域事实，使操作员可在不改变成品库存的前提下记录分批检验与数量结论。

## 被阻塞于

无，可立即开始。

## 范围

- 实现 `finished_goods_inspection_submission`、`finished_goods_qc_record` 的迁移、审计字段、软删除、乐观锁和必要索引。
- 实现送检单与 QC 的核心状态机、Decimal 数量守恒、结论推导和来源/单位快照契约。
- 定义稳定错误码和可被后续 API、E2 消费的可入库余额领域接口。

## 非范围

来源查询、REST 路由、库存事实、发货、应收和前端页面。

## 验收与验证

- 送检草稿、提交、检验中、完成、取消、更正状态均符合 E1 设计。
- QC 合格、条件接收、不合格、混合结论由数量推导，且数量严格守恒。
- 迁移、Prisma 生成、类型检查和领域单元测试通过。
