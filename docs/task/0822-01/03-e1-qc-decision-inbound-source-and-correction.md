# E1 QC 判定、可入库来源与更正预览

## 状态

已完成（2026-08-22）

## 目标

让 QC 操作员按合格、条件接收和不合格数量完成分批检验，并让 E2 获得唯一、只读、可追溯的成品可入库来源。

## 被阻塞于

02 E1 厂内/外加工待送检来源与送检工作流。

## 范围

- 提供 QC 记录创建、查询、可入库来源查询、影响预览和更正 API。
- 实现数量守恒、分批覆盖、条件接收标识、可入库余额和不合格来源门禁。
- 对已被下游消费的 QC 返回明确风险和阻止破坏性更正；未消费 QC 通过可审计更正闭环处理。

## 非范围

成品入库、不良品库存、返工/报废实物处理和发货。

## 验收与验证

- 四类 QC 结论的数量与可入库余额正确，且不产生库存事实。
- 有效 QC 累计不得超过送检数量；重复/并发请求不重复计量。
- 已有下游引用时影响预览列出风险并禁止原位修改；所有更正保留原因和审计。
- 单元、PostgreSQL 集成和 HTTP 契约测试通过。
