# E1 厂内/外加工待送检来源与送检工作流

## 状态

已完成（2026-08-22）

## 目标

让 QC 操作员从 D7 厂内完工和 D6 外加工成品回厂来源创建、提交和取消成品送检单，并由服务端保证分批数量不超来源可用量。

## 被阻塞于

01 E1 成品送检与 QC 核心对象、状态机与迁移。

## 范围

- 提供待送检来源、送检单查询、创建、编辑、提交、取消和来源详情 API。
- 在事务内校验 D7 生产完成/阻塞状态、D6 回厂交接状态、来源单位与累计可送检余额。
- 支持幂等创建、并发保护、附件关联、影响提示和审计。

## 非范围

QC 结论录入、E2 入库事实、直装柜 QC 门禁和前端完整工作台。

## 验收与验证

- 厂内有效完工和 D6 `pending_qc` 成品回厂均可成为送检来源。
- 非就绪、已冲销、已关闭或被 D7 阻塞的来源被拒绝且返回可执行原因。
- 分批送检不会累计超过来源可送检数量；送检本身不产生库存变动。
- 真实 PostgreSQL/API 测试覆盖主路径、超量和并发冲突。
