# 0822-01 E1 成品送检与成品 QC 链路任务

本目录交付 E1：`生产单完成/外加工成品回厂 -> 成品送检 -> 成品 QC 判定 -> 成品可入库来源`。

实施前必须阅读 [E1 成品送检与成品 QC 链路实施设计](../../design/finished-goods-qc-chain-implementation-design.md)、[仓库模块设计](../../design/warehouse-module-design.md)、D6/D7 设计与全局 API 契约。每项完成后更新任务状态、路线图、开发日志和测试证据，并按项目约定单独提交。

## 依赖顺序

```text
01 E1 核心对象、状态机与迁移
  -> 02 厂内/外加工待送检来源与送检工作流
  -> 03 QC 判定、可入库来源与更正预览
  -> 04 D6/D7 联动、权限与审计收口
  -> 05 E1 前端工作台
  -> 06 E1 集成、浏览器验收与链路关闭
```

`01` 完成后可开始 `02`；`03` 依赖 `02`；`04` 依赖 `03`；`05` 依赖 `02-04`；`06` 依赖 `01-05`。
