# E1 成品送检与 QC 工作台前端

## 状态

待开发

## 目标

让仓库和 QC 操作员在真实 Web UI 中完成来源筛选、分批送检、QC 数量分流、风险查看和审计追溯。

## 被阻塞于

02 E1 厂内/外加工待送检来源与送检工作流、03 E1 QC 判定、可入库来源与更正预览、04 E1 D6/D7 联动、权限与审计收口。

## 范围

- 在仓库模块以真实 API 建立待送检来源、送检单、QC 记录和可入库来源页面。
- 使用既定 TanStack Table、shadcn/ui、React Hook Form 规范；展示服务端数量、状态、条件接收/不合格风险、影响预览和审计。
- 提供权限受控操作、加载/空/错误状态与来源跳转，不保留演示数据。

## 非范围

成品库存、出库、应收页面和客户端自行汇总/拼接业务数据。

## 验收与验证

- 登录后可完整完成“选择来源 -> 送检 -> QC -> 查看可入库余额”的真实 API 流程。
- 所有金额/数量、状态、阻塞和来源信息以服务端响应为准；不可用操作显示具体原因。
- Web 类型检查、构建和 Playwright 用户旅程通过。
