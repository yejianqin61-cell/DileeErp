# 0821-03 测试体系与工具建设任务

本目录依据 [测试体系与测试工具建设方案](../../design/testing-system-and-tooling-plan.md) 建立测试工程基础。目标是让每条业务链路在开发完成时同时具备自动化主路径、负向、回退/冲销、幂等和审计验证。

本批只建设测试能力和测试证据，不改变业务规则；测试数据库不可用时必须明确标记环境阻断，不得以 mock 结果冒充真实链路验收。

## 依赖顺序

```text
01 测试脚本、目录与报告基线
  -> 02 测试用户、夹具、隔离与清理
  -> 03 跨模块不变量与断言库
  -> 04 HTTP/API 契约与权限测试
  -> 05 PostgreSQL 集成与事务测试
  -> 06 Playwright 浏览器链路
  -> 07 当前采购链路回归验收
  -> 08 CI、结果归档与部署前质量门禁
```

`04` 可在 `05` 前使用 mock API 或已启动服务进行快速反馈；`06` 和 `07` 必须使用真实 API 与测试数据库。每项任务完成时更新对应任务状态、`docs/test/results/` 测试结果和每日开发日志。
