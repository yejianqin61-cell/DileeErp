## 目标

用真实登录、API 和测试数据库验证用户可见的订单、采购和仓库操作链路。

## 关联决策

## 范围

- 固定 Playwright Chromium 版本和配置；
- 覆盖登录 -> 客户 -> 销售单 -> 订单号 -> 确认 -> BOM 来源；
- 覆盖登录 -> 采购单 -> 分批到货 -> 来料 QC -> 原料入库 -> 应付来源查询；
- 验证页面展示同一 `order_no`、状态、数量和错误提示；
- 失败保存截图、trace、请求 ID 和脱敏响应。

## 非范围

- 绕过 UI 直接写数据库完成验收；
- 移动端、离线、外部系统和视觉快照测试；
- 尚未实现的生产、成品、薪资链路。

## 验收与验证

1. 未登录访问业务页面会跳转登录，登录后会话和权限正常。
2. 主路径能从页面操作完成并在页面查询到下游来源。
3. 重复订单号、无权限、非法数量等负向操作显示稳定错误且页面不展示虚假成功。
4. PostgreSQL 或 API 不可用时测试明确失败原因，不被静态页面生成掩盖。

## 决策记录

浏览器验收只测试用户可见行为和网络结果，数据库事实由集成测试及只读查询断言补充。
