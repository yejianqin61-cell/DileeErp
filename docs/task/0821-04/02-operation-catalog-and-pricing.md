# 0821-04-02 工序池与工序计价

## 状态

已完成

## 目标

让物控员维护全厂共用、可审计的工序池及员工工序计件/计时价格，为后续生产单工序和日报提供稳定来源与价格候选值。

## 关联决策

- `employee-operation-production-order-chain-implementation-design.md` 的 4.1 节
- `production-module-design.md` 的工序池、单价快照和计时/计件口径
- 编码路线图 D2、A7

## 范围

- 提供工序编码、名称、默认单位、启用状态和备注的维护 API 与页面；
- 提供按员工 + 工序 + 计薪方式维护的工序计价，支持生效日、失效日、单价和备注；
- `piece_rate` 与 `time_rate` 作为独立计价口径；同一员工、工序、计薪方式的有效日期不得重叠；
- 工序禁止物理删除，停用后不可用于新生产单；计价变更不改写任何未来已产生的日报价格快照；
- 所有变更保留统一审计与历史查询能力。

## 非范围

- 员工日报录入与最终薪资计算；
- 根据产品规格自动匹配差异单价；
- 生产单、日报、超单或差异告警。

## 验收与验证

1. 物控可创建、编辑、停用和查询工序；已引用工序停用后仍能在历史生产单中显示快照。
2. 物控可维护两类工序单价；重叠生效区间、负数单价、停用员工或工序的计价写入均被拒绝。
3. API 返回工序的稳定 UUID、名称与默认单位，供生产单引用，不以自由文本作为来源。
4. 工序和计价变更均产生可按操作人和时间检索的审计记录。
5. 增加规则、HTTP/API、真实 PostgreSQL 与浏览器用例。
