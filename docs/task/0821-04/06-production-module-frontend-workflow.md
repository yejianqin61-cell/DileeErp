# 0821-04-06 生产模块前端工作流

## 状态

已完成

## 目标

让管理员和物控员在 Web UI 中完成本批生产基础资料维护、草稿生产单创建、工序配置、状态推进、影响确认和审计查看，而不是依赖接口调试工具。

## 关联决策

- `employee-operation-production-order-chain-implementation-design.md` 的 4.5、4.6 节
- 前端统一 TanStack Table、shadcn/ui、React Hook Form 约束
- 编码路线图 D1-D3

## 范围

- 生产基础资料页：部门/岗位/员工、工序池/计价、车间/外加工点的可维护列表与表单；
- 生产单列表：按订单号、生产单号、执行方式、地点和状态筛选；
- 生产单详情/编辑：创建、工序排序、状态动作、影响预览确认、审计和附件；
- API 错误直接转化为用户可见提示；加载、空数据、无权限和停用选项均有明确状态；
- 不显示伪造的日报、库存或外加工进度数据。

## 非范围

- 移动端、离线操作和自动排产；
- 领料、日报、工资、成品、应收应付页面；
- 未确认的复杂工艺模板编辑器。

## 验收与验证

1. 管理员可维护基础资料，物控可维护工序/地点并创建厂内或外加工生产单。
2. 厂内单无工序时启动按钮给出明确业务错误；外加工单不展示日报入口。
3. 列表和详情始终展示 `order_no`、生产单号、状态和地点，停用资料不会作为新建默认选项出现。
4. 匿名访问重定向登录，无权限访问显示统一错误，不出现服务器内部错误或演示数据。
5. Playwright 覆盖物控建立工序并创建/启动厂内生产单的完整 UI 主路径。
