# 0821-04 员工、工序池与生产单链路任务

本目录交付 `员工/部门岗位 -> 工序池与工序计价 -> 生产单（厂内/外加工分支）`。前序链路已经提供认证、RBAC、审计、统一 REST JSON 契约、已确认销售单、`order_no`、已发布 BOM 与原料库存事实；本批复用这些能力，不重建平台层或采购库存逻辑。

实施前阅读 [员工、工序池与生产单链路实现设计](../../design/employee-operation-production-order-chain-implementation-design.md) 和 [生产模块初步设计](../../design/production-module-design.md)。每个任务完成时必须更新本任务状态、每日开发日志、编码路线图和测试证据。

## 依赖顺序

```text
01 组织、员工与生产地点
  -> 02 工序池与工序计价
  -> 03 订单/BOM 到草稿生产单
  -> 04 生产单工序与状态机
  -> 05 影响预览、审计与附件
  -> 06 前端生产工作页
  -> 07 真实链路验收
```

`06` 可在 `03` 后开始页面骨架，但必须在 `05` 后才可宣告页面可用；`07` 必须等待全部前置任务。D4 领退料、D5 日报及告警、D6 外加工直发与 D7 生产进度均不属于本批。
