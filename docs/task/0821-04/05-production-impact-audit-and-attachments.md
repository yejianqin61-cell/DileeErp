# 0821-04-05 生产变更影响预览、审计与附件

## 状态

已完成

## 目标

让操作员在改变已启动生产单的执行方式、地点或关键计划信息前看到影响提示，并可追溯所有生产单操作与关联凭据。

## 关联决策

- `employee-operation-production-order-chain-implementation-design.md` 的 4.3、4.6 节
- `production-module-design.md` 的审计和附件规则
- 编码路线图 A6、D3

## 范围

- 提供已启动生产单关键变更的影响预览；本批至少展示订单号、BOM 版本、工序任务、状态和后续模块尚未建立的提示；
- 生产单详情提供按对象查询的审计历史，包含操作人、执行人、审批人预留、时间、原因、前后值和 `order_no`；
- 复用统一 attachment 系统关联生产单，支持既定附件类别、上传、查看与下载；
- 将关键变更和附件操作纳入既有权限与审计体系。

## 非范围

- 对领料、日报、QC、库存、应收应付等尚未产生的下游事实做实际重算；
- 新建通用告警中心或审批流；
- 外加工物流和质量交接单据。

## 验收与验证

1. 已启动生产单修改执行方式或地点前可获取影响预览，执行时必须提供原因。
2. 审计记录能关联订单号、生产单和工序任务，并在业务逻辑删除后继续可查。
3. 附件不必上传但可与生产单关联，且遵循统一访问权限。
4. 未授权用户无法读取审计和附件；关键变更的 API 与浏览器错误可见。
5. 用 API 与真实 PostgreSQL 测试验证审计不可因生产单逻辑删除而丢失。
