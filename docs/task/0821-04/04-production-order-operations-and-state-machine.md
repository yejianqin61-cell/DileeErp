# 0821-04-04 生产单工序与状态机

## 状态

已完成

## 目标

让物控员为厂内生产单建立有顺序和数量目标的工序任务，并用受控状态机启动、暂停、完成、关闭或恢复生产单。

## 关联决策

- `employee-operation-production-order-chain-implementation-design.md` 的 4.1、4.4 节
- `production-module-design.md` 的工序快照、生产单状态与删除规则
- 编码路线图 D3

## 范围

- 为生产单提供工序任务新增、编辑、排序、取消和查询 API；保存工序名称与单位快照、顺序、目标数量及取消原因；
- 厂内生产单启动前至少有一条有效工序，外加工生产单可无工序；
- 实现 `draft -> in_progress <-> paused -> completed -> closed`，以及已完成单恢复生产中的受控动作；
- 草稿外状态不可逻辑删除；完成、关闭、恢复和例外状态动作都要求原因并写审计；
- 为下一批日报预留暂停状态禁止新增/修改日报的服务端门禁，不在本批实现日报。

## 非范围

- 工序日报、员工日报、累计完成量、超单和日报差异告警；
- 自动完成或自动关闭生产单；
- 原料领退料、库存扣减和成品 QC。

## 验收与验证

1. 厂内生产单可以选择启用工序、维护唯一顺序和正目标数量，且历史详情显示工序快照。
2. 厂内生产单无有效工序不能启动；外加工单可按最小追溯规则启动。
3. 非法状态转换、草稿外删除、停用工序引用和跨类型地点均返回稳定业务错误。
4. 状态动作、排序、数量调整、取消及删除限制都有审计事件和操作原因。
5. 规则、HTTP/API、PostgreSQL 和浏览器用例覆盖状态机的允许/拒绝路径。
