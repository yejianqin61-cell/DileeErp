# Task 01：E4 应收、收款与核销数据模型

## 目标

建立应收来源、客户收款和多对多核销明细模型及迁移。

## 实施要求

- 新增 `ReceivableSource`、`CustomerPayment`、`ReceivableAllocation`。
- 应收来源唯一关联已过账出库单，保存订单、客户、价格/税率/币种和金额快照。
- 收款保存日期、金额、方式、银行流水、附件、状态和审计字段。
- 核销明细支持一收款多来源、一来源多收款，并约束重复分配。
- 金额使用 `numeric(18,4)`，建立订单、客户、状态和余额查询索引。

## 完成标准

迁移可部署，Prisma Client 生成通过，既有 E3 模型不回归。
