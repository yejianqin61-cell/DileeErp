# 06 财务单据草稿治理

## 状态
已完成

## 目标
让应收、应付、收付款、对账和工资单据遵循一致的草稿编辑、版本冲突和受控回退规则。

## 范围
- 草稿允许 PATCH 编辑并做乐观版本校验。
- 已确认/过账记录显示影响预览，使用调整、冲销、退款、补收或补付。
- 所有更正记录原因、操作人、时间和前后快照。

## 验收
- 并发版本冲突不会覆盖他人修改。
- 已付款/已核销事实不能回退为草稿。

## 完成记录

- 新增应收来源草稿编辑接口，支持金额、到期日、金额原因和备注维护。
- 新增工资付款草稿编辑接口，支持金额、付款日期、付款方式、银行参考和备注维护。
- 两类接口均拒绝非草稿状态，已确认/已过账事实继续通过原有冲销或调整流程处理。
- API 构建及 67 项单元测试通过；真实并发 PostgreSQL 验收仍需专用环境。
