# 03 应付与库存差异治理

## 状态
已完成

## 认领

负责人：Codex
开始日期：2026-08-31

## 目标
统一数量、单价、税率、币种、金额快照和外部余额差异处理。

## 范围
- 应付来源、应付条目、付款和应付对账使用同一批次/采购单快照。
- 已付款记录只能通过调整、补付、退款或冲销更正。
- 对账差异必须有原因、处理状态和审计记录。

## 验收
- 重复接收、重复付款和超额分配被拒绝或幂等。
- 应付余额、付款分配和对账差异可按订单号重算。

- 验证：API 构建和单元测试通过。
