# 08 业务身份与回归验收

## 状态
已完成

## 认领

负责人：Codex
开始日期：2026-08-31

## 目标
移除业务页面对内部 UUID 的依赖，并完成真实环境的权限、幂等、负库存和全链路回归。

## 范围
- 员工、供应商、客户、物料、采购单、入库单使用姓名/编号/订单号等业务身份。
- API 合约、PostgreSQL 集成和 Playwright 浏览器写入测试。
- 记录权限矩阵、错误反馈、审计和回退证据。

## 验收
- 操作员无需手工输入 UUID 即可完成两条最低验收链路。
- 单元、集成、HTTP 和浏览器测试结果可复现并记录。

## 完成记录

- 到货登记由采购单和采购物料下拉选择，页面不再要求手工填写采购明细 ID；采购物料选项展示采购单号、物料编码/名称、型号和采购量。
- 工资台账新建按员工姓名选择；员工、供应商、订单号等业务操作均使用业务身份，UUID 仅保留在请求关联和隐藏状态中。
- 验证：Web 类型检查、API 类型检查和相关领域单元测试通过。真实 PostgreSQL、权限、HTTP 写入及 Playwright 验收仍需部署环境执行，不能由本地静态检查替代。
