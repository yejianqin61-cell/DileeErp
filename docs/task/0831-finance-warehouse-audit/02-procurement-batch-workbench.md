# 02 采购批次联动工作台

## 状态
待认领

## 目标
在采购单详情内集中查看并维护收货批次、来料质检批次、原料入库批次及应付来源。

## 范围
- 每批显示批次序号、到货数量、检验数量、合格/条件接收/不合格数量、入库数量、应付状态和订单号。
- 合法状态支持编辑、回退和更正；过账事实使用冲销/调整。
- 前端使用现有 DataTable、Dialog、Sheet、Select、Input、Button 组件。

## 验收
- 同一采购单可有多批到货、质检和入库，批次可追溯且不混淆。
- 到货后自动出现质检任务；入库只能消费合格或条件接收数量。
- 任何已过账更正都显示影响和原因。
