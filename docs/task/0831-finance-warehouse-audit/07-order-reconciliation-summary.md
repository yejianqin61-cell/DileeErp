# 07 订单联动对账摘要

## 状态
已完成

## 认领

负责人：Codex
开始日期：2026-08-31

## 目标
按订单号集中呈现采购、仓库、质检、生产、应收、应付的数量/金额差异和阻塞明细。

## 范围
- 采购需求、下单、到货、QC、入库、待应付、已确认应付、付款均可对账。
- 生产计划、日报、领料、成品 QC、入库、出库、应收、收款均可对账。
- 缺失、超收、超发、超单和未核销状态形成可解释告警。

## 验收
- 订单工作台摘要与各模块事实一致，金额和数量可追溯到来源单据。

## 完成记录

- 订单摘要补充 BOM 需求、采购下单、到货、来料质检、原料入库、生产计划/工序完成、领料/退料/报废、成品 QC/入库/出库、应收核销、应付核销和待应付来源金额。
- 数量或分配超额时生成稳定、可解释的订单级 blocker。
- 验证：API TypeScript 检查、API 构建、订单工作台领域测试通过。
