## 2. 这意味着什么

Phase 1 解决"为什么选不到"，Phase 2 解决"改一行要退一整单"，Phase 3 把这两件事摆到用户走得到的路径上。三个阶段的落点刻意都在**已有页面已有的位置**：新建弹窗、物料块头、计划编号的 `title` —— 没有新页面、没有新路由、没有新增列（1366px 的宽度预算已经用完）。

行级退回按钮的判据与服务端同一条线（零到货 + 单状态），所以界面上不会出现"点了必然被拒"的入口。这点比按钮本身重要：可发现性与可信度是同一件事的两面。
