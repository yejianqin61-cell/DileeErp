## 共同完成标准

- 页面以订单号、来源编号、客户/供应商名称、物料名称展示，UUID 只作内部关联；
- 所有写操作沿用既有状态机与审计，不新增静默覆盖：批量确认只做 `draft → confirmed`；
- 双击任意行都能看到该条目的全部字段与当前可执行操作；
- 行为由真实渲染 + 真实点击的组件测试钉住，不是源码正则；
- **未在真实 PostgreSQL 上验证**（本机 Docker 未运行、5432 未监听），因此迁移与两个新端点的
  事务行为、DTO 与鉴权尚未端到端验证，见 `docs/log/2026-09-14.md`。
