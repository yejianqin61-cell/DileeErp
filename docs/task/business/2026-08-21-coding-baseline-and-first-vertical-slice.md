## 目标

依据《产品建模收束与编码基线》和《编码准备计划》，复核平台基线并实现销售单草稿到 BOM 版本引用占位的首个纵向切片。

## 范围

- 复核并修正平台构建、测试、迁移和 Prisma 生成问题；
- 实现订单号唯一性校验和销售单核心实体；
- 实现销售单草稿、编辑、确认、逻辑删除及状态记录；
- 保存销售单表单定义版本；
- 提供 BOM 版本引用占位，不实现 BOM 明细业务字段；
- 提供订单链路摘要查询。

## 非范围

- 完整 BOM/QC 字段和检验流程；
- 采购、库存、生产、财务、人事业务；
- 审批人/批准人具体角色配置；
- 移动端、离线、外部系统对接。

## 验收

1. 重复 `order_no` 无法创建，错误符合统一 REST JSON 契约。
2. 销售单确认后状态变更有状态记录和审计日志。
3. 编辑已被下游引用的销售单时返回影响预览，确认后保留原版本并生成新版本，不静默覆盖。
4. 逻辑删除不删除数据库事实，历史查询仍可追溯。
5. BOM 引用能追溯到销售单版本，但未定义的 BOM/QC 扩展字段不会被硬编码。
6. API、类型检查和关键前端流程测试通过。
