# T7 现金流量表补齐成本类科目

## 1. 这份任务在哪

- **Phase 2 报表不再靠名字认科目**，目标是财务新增一个科目时三张报表都点名它没归位。
- **本任务补上现金流量表按名字逐条硬编码漏掉的六条成本类科目**：生产成本 / 劳务成本 / 制造费用 / 工程施工 / 机械作业 / 辅助生产成本，今天一条都落不进任何行。
- **开始于**：Phase 1 已完成。**后续等它**：报表行映射落数据（这六条届时仍要保留）。

## 2. 开发前需要知道什么

**先读**

- `apps/api/src/modules/finance/finance-three-statements.ts` — 现金流量表第 5/6/8 行对成本类的三组 `named(...)`。
- `apps/api/test/unit/finance-three-statements.test.cjs` — 覆盖度守卫与「成本类两拨」那两条用例。
- `docs/audit/accounting-subject-diagnosis-2026-11-11.md` P1-6 — 这六条为什么算真缺口。

**已定**

- 「制造费用」这类在制品性质的成本类支出算**经营现金流出**，不归投资/筹资。
- 归属口径：与它们同族、已在表里的科目走同一条行，不新开行。
- 这是数据补齐，不改落行逻辑。

**边界与缝**

- 触及现金流量表行定义与覆盖度断言。不碰其他两张表。
- 缝：既有报表内核测试入口。不新增缝。

**运行**

- `npm run build --workspace=@dilee/api`
- `node --test apps/api/test/unit/finance-three-statements.test.cjs`
- `npx tsc -p apps/api/tsconfig.json --noEmit`

**未知**

- 六条里「辅助生产成本」「劳务成本」是否真会出现现金支出，需要按财务口径判断；若不确定就归到与「基本生产成本」同一行，并在注释里标出口径待确认。

## 3. 流程

1. 读上面三个文件，用一句话复述本任务。
2. 写一条会失败的测试：六条科目各自的凭证都要落进现金流量表某一行，不落进未归位。
3. 把它们加进对应行的 `named(...)`。
4. 确认没有和已有行重复认领（覆盖度守卫会报）。
5. 跑构建、类型检查与测试。
6. 提交。
