# T6 资产负债表补缺口出口

## 1. 这份任务在哪

- **Phase 2 报表不再靠名字认科目**，目标是财务新增一个科目时三张报表都点名它没归位。
- **本任务把三张报表里唯一没有出口的那张补上**：利润表和现金流量表都会在表尾说「这些科目没归位」，资产负债表什么都不说。
- **开始于**：Phase 1 已完成。**后续等它**：报表行映射落数据。

## 2. 开发前需要知道什么

**先读**

- `apps/api/src/modules/finance/finance-three-statements.tables.ts` — 三张表的构建器，看利润表与现金流量表怎么写缺口。
- `apps/api/src/modules/finance/finance-three-statements.ts` — `BalanceSheetResult.unmapped` 已经算出来了，只是没人用。
- `apps/api/test/unit/finance-three-statements-tables.test.cjs` — 表尾文案怎么断言的。

**已定**

- 资产负债表的缺口文案与利润表同口径：「未归入任何报表行的科目（本期有发生额）」。
- 勾稽不平衡时的提示要`先`看有没有未归位科目，再看是不是期初没录——现在的顺序把一切差额都归因于期初。

**边界与缝**

- 触及资产负债表表构建器与它的测试。不碰内核的归集逻辑。
- 缝：既有表构建器测试入口。不新增缝。

**运行**

- `npm run build --workspace=@dilee/api`
- `node --test apps/api/test/unit/finance-three-statements-tables.test.cjs`
- `npx tsc -p apps/api/tsconfig.json --noEmit`

**未知**

- 缺口在资产侧还是权益侧不明确：一份未归位的科目属于哪一侧都可能。若内核无法判定侧别，就两侧合计后统一写在表尾。

## 3. 流程

1. 读上面三个文件，用一句话复述本任务。
2. 写一条会失败的测试：有未归位科目时资产负债表表尾必须出现那句提示。
3. 在构建器里把 `unmapped` 写进表尾。
4. 调整勾稽不平衡的提示顺序：先提未归位科目。
5. 跑构建、类型检查与测试。
6. 提交。

## 4. 测试用例

| 用例 | 输入 | 期望 | 缝 |
| --- | --- | --- | --- |
| 1 | 一份金额 100 的未归位科目 | 表尾出现该科目名与金额 | 表构建器 |
| 2 | 没有任何未归位科目 | 表尾不出现该句（不制造噪音） | 表构建器 |
| 3 | 有未归位科目且勾稽不平 | 提示先提未归位，再提期初 | 表构建器 |
| 4 | 勾稽不平但没有未归位科目 | 提示仍如期初口径 | 表构建器 |
