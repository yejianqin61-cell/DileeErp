# 0821-07-03 外加工直发/签收更正、冲销与影响预览

## 状态

已完成（2026-08-22）

## 目标

让操作员能在录入直发或签收错误时先看到库存、应付来源和下游引用影响，再以可审计冲销或补充事实完成更正，不直接改写已发生的物流事实。

## 关联决策

- D6 设计 4.6 节。
- D4、D5 已交付的影响预览、冲销和审计模式。

## 范围

- 为已发生直发/签收提供影响预览、冲销、补充记录和剩余可冲数量校验。
- 将冲销后受影响的批次状态、签收累计、采购可履约/应付来源候选和短收提示放在同一事务内重算。
- 在前端提供明确的“草稿编辑”与“已发生更正”分支，并展示自动联动与需人工处理的下游引用。
- 记录更正原因、原业务事实、影响快照、操作人、时间和前后值。

## 非范围

- 自动冲销已确认应付、付款或任何后续财务单据。
- 回厂、直装柜和成品业务的更正。

## 验收与验证

1. 草稿可原位编辑/删除，已直发或已签收记录不能原位删除。
2. 冲销数量不能超过剩余可冲数量；缺少原因、版本冲突或重复幂等请求均按全局契约处理。
3. 更正前预览明确列出应付来源与风险提示变化；提交后批次状态、来源候选和审计在同一事务内一致。
4. 下游已引用时系统不静默改写下游事实，并在界面和 API 返回中标明人工处理项。
