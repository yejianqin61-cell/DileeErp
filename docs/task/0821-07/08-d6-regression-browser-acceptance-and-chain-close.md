# 0821-07-08 D6 回归、浏览器验收与链路关闭

## 状态

待开发

## 目标

以独立 PostgreSQL、真实 API 和真实浏览器关闭 D6，并归档可复查证据，确认直发不入厂内库存、签收形成应付来源、回厂和直装柜保持正确边界。

## 关联决策

- D6 设计第 5、6、7 节。
- 测试体系与测试工具建设方案。

## 范围

- 增加 D6 PostgreSQL 集成、HTTP/API 契约和必要单元测试，覆盖 D6 与 D1-D5 回归。
- 增加 Playwright 主旅程：登录、外加工批次、直发、分批签收、余料回厂、成品回厂来源、直装柜、更正/审计。
- 执行质量门禁，归档测试报告，更新编码路线图和每日开发日志并明确 D6 关闭范围。

## 非范围

- 为未实现的 E1-E5、F、G 链路补代码，或以 mock/手工改库替代真实验收。
- 厂内部署、性能压测、历史迁移和外加工结算。

## 验收与验证

1. D6 集成、HTTP/API、单元和既有 D1-D5 回归均通过，且使用独立 PostgreSQL 测试库。
2. 浏览器验收证明直发与签收不改变厂内原料库存，签收可生成应付来源，余料回厂须经 QC/入库才影响原料库存，成品回厂/直装柜不提前改变成品库存。
3. 更正、冲销、权限拒绝、审计和附件在真实 API/浏览器路径中可验证。
4. 测试证据、路线图、开发日志和 D6 状态一致；未实现的 E/F/G 依赖被明确保留为后续工作。
