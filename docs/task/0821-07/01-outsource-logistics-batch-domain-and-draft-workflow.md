# 0821-07-01 外加工物流批次领域模型与草稿工作流

## 状态

已完成（2026-08-22）

## 目标

让采购、物控和仓库操作员能够围绕一张有效外加工生产单及其采购单明细创建、查看和维护“外加工物流批次”草稿，使每批待直发原料从创建之初就可追溯至 `order_no`、物料、外加工点和操作人。

## 关联决策

- D6 设计 2、4.1、4.2、4.7 节。
- 编码路线图 D6。

## 范围

- 建立外加工物流批次及其审计、附件、采购明细、生产单、外加工点和物料快照关系；完成必要迁移、索引、外键和枚举。
- 提供批次草稿的列表、详情、创建、编辑、逻辑删除与生产单上下文入口；页面可选择来源采购单明细并展示服务端返回的快照。
- 服务端校验外加工生产单、启用外加工点、采购明细物料/订单一致性、非负十进制数量和生产单可写状态。
- 复用 UUID、审计、逻辑删除、附件、RBAC、`order_no` 冗余追溯和 REST JSON 平台能力。

## 非范围

- 实际直发、签收、应付来源、回厂、直装柜、库存变动和财务联动。
- 外加工现场生产过程、日报、薪资和加工费。

## 验收与验证

1. 有效外加工生产单可从关联采购单明细创建多张批次草稿，且列表、详情始终展示相同 `order_no`、生产单、地点、物料与单位快照。
2. 厂内生产单、停用地点、订单不一致采购明细、关闭生产单和非法数量均被服务端拒绝。
3. 草稿可编辑和逻辑删除；创建、编辑、删除与附件关联都保留审计。
4. 未认证和越权请求遵守全局 401/403 契约；既有 D1-D5 schema 与 API 不回归。

## 阻塞关系

无；依赖已完成的 C2、D3、认证、附件和审计基础能力。
