# 0821-07-07 D6 前端工作流与权限收口

## 状态

待开发

## 目标

将 D6 已交付的直发、签收、余料回厂、成品回厂和直装柜能力组织为操作员可连续使用的界面，并确保页面只展示和执行当前角色被授权的动作。

## 关联决策

- D6 设计 4.7 节。
- 全局 RBAC、附件和 API 契约。

## 范围

- 在采购、生产单详情与仓库入口提供一致的外加工交接入口、列表、详情、筛选、状态和审计查看。
- 实现直发/签收、回厂和直装柜的表单校验、服务端错误呈现、附件关联、影响预览和更正入口。
- 按既有 RBAC 收口采购、仓库、物控、财务、销售和管理员的查看/操作权限。
- 保持所有数量、库存、应付来源和状态由 API 返回，前端不自行跨表计算。

## 非范围

- 新增审批流、移动端、离线操作、全局告警中心或 Excel 导出。
- 代替 02-06 实现任何后端业务规则。

## 验收与验证

1. 授权用户可从外加工生产单上下文完成各自允许的 D6 操作，并在列表和详情看到准确的状态与订单追溯。
2. 未授权动作不显示或被 API 拒绝；服务端 401、403、409、422 错误可读且不丢失输入。
3. 所有更正操作先展示影响预览，提交后审计和附件在详情可见。
4. 前端生产构建通过，且不破坏 D1-D5 页面。

## 阻塞关系

被 02、03、04、05、06 阻塞；完成后阻塞 08。
