# 0821-07-04 外加工余料回厂与原料 QC/入库衔接

## 状态

待开发

## 目标

让仓库操作员登记外加工余料回厂，并将其作为原料 QC 和原料入库的可追溯来源；余料只有在实际回厂、QC 合格并完成入库后才增加厂内可用库存。

## 关联决策

- D6 设计 4.1、4.4、4.6 节。
- D2 原料 QC/入库及 D4 库存事实实现。

## 范围

- 建立余料回厂交接事实及其草稿、待 QC、QC 结果、入库完成状态。
- 提供生产单上下文创建、查询、提交 QC 和衔接既有原料 QC/入库的 API 与页面。
- 将回厂交接作为原料 QC/入库来源；同步展示回厂待验收数量、QC 结果和入库引用。
- 支持草稿删除和已发生回厂的冲销/风险提示，且不直接编辑原料库存余额。

## 非范围

- 外加工点库存余额核算、余料外部报废、单位换算和采购退货。
- 成品回厂与成品 QC。

## 验收与验证

1. 余料回厂创建后不改变厂内原料库存，只有 QC 合格并入库后才产生原料库存事实。
2. 回厂记录、QC 记录、入库记录和库存流水均能追溯至同一 `order_no`、外加工生产单和来源交接。
3. QC 拒绝或入库撤销后，回厂状态正确反映，不保留“已入库”的虚假状态。
4. 操作员可在浏览器完成余料回厂到 QC/入库的主要路径，并查看审计和附件。

## 阻塞关系

被 01 阻塞；依赖已完成的 D2/D4 原料 QC 与入库能力；完成后阻塞 07、08。
