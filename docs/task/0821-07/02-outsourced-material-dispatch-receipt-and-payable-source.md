# 0821-07-02 外加工原料直发、分批签收与应付来源

## 状态

待开发

## 目标

让采购操作员能把外加工物流批次标记为实际直发，并由外加工对接人分批登记签收；已签收数量可作为采购应付来源候选，但不会增加厂内原料库存。

## 关联决策

- D6 设计 4.2、4.3、4.7 节。
- D2 采购到货、QC、入库与应付来源既有实现。

## 范围

- 建立直发与签收业务事实、状态迁移、累计数量计算及直发/签收审计。
- 提供直发、分批签收、批次状态查询及采购/生产单上下文页面操作。
- 将有效签收扩展为应付来源候选，明确区分厂内入库来源和外加工直发签收来源。
- 保证直发与签收不写入厂内原料可用库存或厂内入库单；签收凭据或备注至少一项必填。
- 短收允许保存但要求原因并生成可查询风险提示。

## 非范围

- 已发生业务的冲销、更正及跨下游影响预览。
- 供应商付款、加工费结算、厂内 QC 或外加工现场质检。

## 验收与验证

1. 一张批次可完成一次直发和多次签收，状态按累计签收数量正确变为已发出、部分签收或已签收。
2. 签收超过未冲销直发数量、重复直发、非法日期和无凭据/备注的签收均被拒绝；短收可保存且有原因与风险提示。
3. 直发/签收前后厂内原料库存不变；有效签收数量可被应付来源查询读取，未签收数量不能被读取。
4. 操作员可在页面完成直发、签收并查看累计数量、来源状态与审计记录。
