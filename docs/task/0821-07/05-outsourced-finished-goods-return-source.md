# 0821-07-05 外加工成品回厂来源事实

## 状态

已完成（2026-08-22）

## 目标

让仓库操作员登记外加工成品回厂，形成可被后续成品 QC 和成品入库链路消费的待验收来源，而不提前把未验收成品计入厂内库存。

## 关联决策

- D6 设计 4.1、4.4、4.6 节。
- E1/E2 后续成品 QC 与成品库存边界。

## 范围

- 建立类型为成品回厂的交接事实、来源查询、附件、审计和状态机。
- 在外加工生产单上下文提供创建、编辑草稿、提交待 QC、详情和影响预览界面。
- 向后续 E1/E2 暴露稳定、只读的成品回厂待验收来源，不写入厂内成品库存。
- 校验外加工生产单、订单一致性、成品描述、单位、正数量、日期和可写状态。

## 非范围

- 成品检验项目、QC 判定、成品入库、不良品、库存余额、发货与应收。
- 按 BOM 或外加工原料数量自动反推成品上限。

## 验收与验证

1. 有效外加工生产单可分批登记成品回厂，记录可追溯至 `order_no`、生产单、数量、单位、附件与操作人。
2. 创建和提交待 QC 前后均不产生厂内成品库存变动。
3. 后续链路可按生产单和订单查询未关闭的成品回厂来源，重复提交或非法关联被拒绝。
4. 草稿修改/删除与已发生事实更正均保留影响提示和审计。

## 阻塞关系

被 01 阻塞；完成后阻塞 07、08，并为 E1/E2 提供前置来源。
