# 0821-07 D6 外加工直发、签收、回厂/直装柜链路任务

本目录交付 D6：`外加工生产单 + 采购单明细 -> 原料直发 -> 外加工点签收 -> 余料/成品回厂或直装柜`。

实施前必须阅读 [D6 外加工物料直发、签收、回厂/直装柜链路实施设计](../../design/outsourced-material-direct-delivery-receipt-return-or-direct-container-chain-implementation-design.md)、[采购模块初步设计](../../design/procurement-module-design.md)、[仓库模块初步设计](../../design/warehouse-module-design.md) 与全局 API 契约。每项完成时更新任务状态、编码路线图、开发日志和测试证据。

## 依赖顺序

```text
01 外加工物流批次领域模型与草稿工作流
  -> 02 原料直发、分批签收与应付来源
  -> 03 直发/签收更正、冲销与影响预览
  -> 04 外加工余料回厂与原料 QC/入库衔接
  -> 07 D6 前端工作流与权限收口
  -> 08 D6 回归、浏览器验收与链路关闭

01 -> 05 外加工成品回厂来源事实
01 -> 06 外加工成品直装柜来源事实
05 + 06 -> 07
```

`04`、`05`、`06` 可在 `01` 完成后并行推进。`05` 和 `06` 只提供后续 E 链路消费的来源事实，不提前实现成品 QC、成品库存、应收或报关。
