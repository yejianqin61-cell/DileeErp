# 01 应付来源接收闭环

**Status:** in-progress
**Priority:** P0
**Depends on:** 已有原料入库、PayableSource、SupplierPayableEntry

## 目标

让财务可以从每批原料入库产生的待处理应付来源创建或接收应付条目，过程幂等、可追溯且可见。

## 交付

- 财务 API 提供待处理应付来源查询，支持订单号、采购单号、供应商和状态筛选。
- 单条接收与重复请求返回同一 SupplierPayableEntry，不重复建账。
- 财务页面展示来源批次、入库数量、单价、金额、供应商和订单号，并提供“接收应付”动作。
- 接收后来源与应付条目状态和编号可回查。
- 补充服务/API 测试。

## 验收

原料入库过账 -> 待处理来源出现 -> 接收应付 -> 应付列表出现唯一条目 -> 重复接收不增加条目。
