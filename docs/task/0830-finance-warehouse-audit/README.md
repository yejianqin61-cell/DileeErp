# 财务、仓库及跨模块联动改进任务

本批任务依据 [财务、仓库及跨模块联动审计](../../audit/finance-warehouse-integration-audit-2026-08-30.md) 拆分。每个 task 独立验收、独立提交，完成后更新状态与测试证据。

## 执行顺序

```text
01 应付来源接收闭环
  -> 02 应付对账
  -> 03 财务单据编辑与受控回退
  -> 04 仓库库存总览与原料工作区
  -> 05 订单号联动工作台
  -> 06 跨模块回归与权限验收
```

## 共同约束

- `order_no` 是跨模块业务身份；UUID 只作内部关联键。
- 库存余额由有效库存事实汇总，禁止直接编辑。
- 已确认事实不得静默覆盖；更正使用调整、冲销、退款或补充事实。
- 新增页面和表单使用现有组件库，不使用原生业务控件或浏览器弹窗。
- 每个 task 完成后运行相关类型检查/测试，并使用 Conventional Commits 提交。
