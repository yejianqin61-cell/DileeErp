# 10 — 财务页面治理

**What to build:** 将应收、收款、应付、付款、核销、冲销和对账治理为低密度、可追溯的财务工作台。

**Blocked by:** 09 — 人事页面治理

**Status:** ready-for-agent

- [ ] 应收和应付来源支持筛选、详情、确认和影响预览
- [ ] 收款、付款新建使用客户/供应商、金额、日期和币种表单
- [ ] 分批核销支持在 Sheet 中选择来源和输入核销金额
- [ ] 过账、冲销和对账处理使用 AlertDialog 和原因字段
- [ ] 余额、状态、order_no 和审计时间线在详情中可见
- [ ] 完成成品出库到应收收款、原料入库到应付付款的真实验收
