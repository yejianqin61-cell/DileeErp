# 01 — 建立 shadcn/ui 前端组件基础层

**What to build:** 建立项目统一维护的 shadcn/ui 风格组件基础层，替换当前零散的自建按钮、徽标和面板样式，为后续所有业务页面提供稳定、可访问、可组合的 UI 原语。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 建立组件配置和统一组件目录约定
- [ ] 提供 Button、Badge、Card、Separator、Skeleton、Label 等基础组件
- [ ] 提供统一设计 token、焦点态、禁用态、错误态和响应式尺寸
- [ ] 组件支持键盘操作和可访问名称
- [ ] 不改变现有 API 请求和业务字段
- [ ] 通过类型检查、lint 和生产构建
