# 平台任务 07：通用状态机

## 状态
已完成（状态定义和转换数据库验证待 PostgreSQL）

## 依赖
平台任务 05、06、10。

## 目标

提供统一的状态定义、合法转换校验和状态变更记录，避免业务模块散落字符串判断。

## 范围

- 状态定义、转换定义和实体当前状态关联。
- 统一状态机服务和状态变更接口。
- 原状态、目标状态、实体 ID、操作人、时间和备注记录。
- 非法转换、停用状态和并发冲突处理。

## 非范围

不实现订单自动流转或具体模块状态集合。

## 验收

- 合法转换成功并记录变更。
- 非法转换返回稳定业务错误且不修改当前状态。
- 停用状态不能用于新转换，历史记录仍可展示。
- 并发更新不会静默覆盖另一操作员的状态变更。
