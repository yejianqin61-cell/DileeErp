# 平台任务 01：应用基础层

## 状态
已完成

## 依赖
无。所有其他后端平台任务依赖本任务的应用启动与配置约定。

## 目标

建立 NestJS 应用级基础设施：环境配置、统一响应、异常处理、参数校验、分页/排序/筛选约定、健康检查和结构化日志入口。

## 范围

- 配置模块及启动时环境变量校验。
- `/api/v1` 路由前缀和统一 JSON 成功响应。
- 全局异常过滤器及稳定错误码。
- DTO 校验管道。
- 通用分页、排序和筛选参数解析。
- 健康检查和结构化日志。
- 为 API 文档入口预留配置。

## 非范围

不创建业务实体、业务数据库表、认证流程或附件存储。

## 验收

- 缺少必需环境变量时应用以可读错误启动失败。
- 成功接口返回 `{ data, meta }`，异常返回 `{ error: { code, message, details } }`。
- 参数错误返回 `400` 和稳定错误码；未处理异常不会泄露堆栈。
- 健康检查可验证应用存活，并为数据库检查预留分项。
- 日志包含时间、级别、请求标识、HTTP 方法、路径和耗时。

## 验证

已完成：`npm run typecheck --workspace=@dilee/api`、`npm run build --workspace=@dilee/api`，启动 API 调用 `GET /api/v1/health` 返回 `200` 和统一 JSON 响应；环境校验、请求 ID、请求完成日志和全局异常/DTO 校验已接入。平台测试任务覆盖公共契约；数据库依赖验证单独记录在任务 09。
