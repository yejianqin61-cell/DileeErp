# 平台任务 06：可配置字典

## 状态
已完成（持久化 CRUD 验证待 PostgreSQL）

## 依赖
平台任务 04、05、10。

## 目标

为状态、币种、计量单位等跨模块枚举提供数据库驱动的增删改查和启停能力。

## 范围

- 字典类型与字典项模型。
- 管理员维护接口和模块授权读取接口。
- 排序、显示名称、稳定 key、启用状态和备注。
- 已被引用项不可物理删除，只能停用/逻辑删除。
- 初始模块 key 和常用币种/单位种子数据的导入机制。

## 非范围

不定义生产工序、订单状态的最终业务值，不替业务负责人决定字段。

## 验收

- 管理员可新增、修改、停用字典项。
- 停用项不出现在新建业务单据可选列表，但历史引用仍可读。
- 非管理员不能修改字典。
