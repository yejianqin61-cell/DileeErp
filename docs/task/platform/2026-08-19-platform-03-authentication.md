# 平台任务 03：身份认证与用户上下文

## 状态
已完成（持久化登录验证待 PostgreSQL）

## 依赖
平台任务 01、02、10。

## 目标

实现独立操作员账号、登录、密码安全存储和当前用户上下文，为权限和审计字段提供可靠用户来源。

## 范围

- 用户状态（启用/停用）。
- 登录凭据和安全密码哈希。
- Session 或令牌机制的实现与失效策略。
- `GET /api/v1/auth/me` 当前用户接口。
- 未登录请求统一返回 `401`。
- 服务端注入当前用户，不信任客户端 `created_by`/`updated_by`。

## 非范围

不实现复杂单点登录、短信找回、手机端认证或外部身份源。

## 验收

- 独立账号能登录、退出和查询当前用户。
- 错误凭据不会泄露账号存在性或密码信息。
- 停用账号不能登录，既有会话按约定失效。
- 审计上下文可被后续写入服务读取。
