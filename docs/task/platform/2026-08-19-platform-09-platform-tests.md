# 平台任务 09：平台质量门禁与备份恢复

## 状态
待认领

## 依赖
平台任务 01-08、10。

## 目标

为平台层建立自动化契约/集成测试，并验证 PostgreSQL 和附件数据的本地备份恢复流程。

## 范围

- API 响应、错误码、参数校验、分页测试。
- 认证、授权、审计、逻辑删除测试。
- 字典、状态机、附件安全和下载授权测试。
- 数据库迁移重复执行测试。
- 每日备份、恢复演练和记录模板。

## 验收

- CI 或本地命令可一次运行平台测试集。
- 关键失败场景有明确断言，不只验证 HTTP 200。
- 空 PostgreSQL 可重复迁移并恢复平台数据。
- 备份文件和恢复步骤存放厂内，不依赖云端。
