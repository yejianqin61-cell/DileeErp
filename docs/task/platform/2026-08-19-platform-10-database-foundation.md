# 平台任务 10：PostgreSQL 迁移与平台数据基础

## 状态
已完成（迁移运行验证待 Docker Desktop）

## 依赖
平台任务 01。

## 目标

选择并配置迁移工具，仅创建身份、权限、字典、状态机和附件所需的平台表。

## 范围

- PostgreSQL 连接配置和迁移命令。
- 迁移文件版本管理、回滚策略和空库初始化。
- 用户、角色/模块授权、字典、状态定义/转换、附件/关联表。
- 平台表统一 UUID、审计字段和逻辑删除。
- 本地开发种子数据与生产环境种子数据边界。

## 非范围

不创建订单、生产、物料、采购、库存、财务、人事或客户业务表；不创建万能单据/属性表。

## 验收

- 空 PostgreSQL 执行迁移成功，重复执行幂等。
- 平台表约束、外键、唯一键和审计字段可检查。
- 回滚/重建步骤有文档并可执行。
- 后续业务模块能通过明确迁移追加表，不需修改平台历史迁移。
