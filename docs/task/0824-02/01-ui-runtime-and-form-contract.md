# 01 — 统一 UI 运行时与表单契约

**What to build:** 让全站具备可直接复用的 shadcn/ui 运行时、表单校验、Toast、错误状态和确认交互，为业务页面迁移提供稳定入口。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 应用根部挂载 Toast Provider 和统一反馈入口
- [ ] FormField 支持标签、必填、字段错误、提交中和服务端错误
- [ ] Select 支持业务编号/名称显示、空选项、禁用和错误状态
- [ ] AlertDialog 支持过账、关闭、冲销、软删除确认
- [ ] 表单提交失败时保留输入，关闭未保存表单时有离开提示
- [ ] 用一个真实业务表单完成浏览器验收
