## 目标

把 D5/D6 来源事实的新增、编辑、逻辑删除、恢复和冲销与 D7 摘要联动，保证更正后生产进度和订单状态自洽。

## 依赖

`02-d7-progress-read-model-and-rebuild-api.md`。

## 范围

- D5 工序日报变更触发受影响生产单/订单重算。
- D6 成品回厂、直装柜及其冲销触发交付计量和外加工状态重算。
- 来源被冲销、工序取消、目标数量变化时的影响预览和 409/风险提示。
- 事务内更新摘要、阻塞原因、状态变化和审计事件。
- 并发版本/条件更新，避免旧摘要覆盖新摘要。

## 非范围

不反写库存、应收应付或员工薪资；不自动修改来源事实。

## 验收与验证

- 日报删除/恢复、D6 回厂/直装柜冲销后摘要正确变化。
- 事务中任一环节失败时来源和摘要均回滚。
- 并发更新产生稳定冲突，不丢失较新状态。
- 审计包含前后状态、触发来源、订单号、请求 ID 和操作人。

## 决策记录

- D7 只读汇总来源，不复制或覆盖 D5/D6 审计事实。
