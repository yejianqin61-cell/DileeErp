## 目标

落实“进退皆可”：为采购、QC、入库和应付来源提供受控更正、退供应商/冲销入口、影响预览与差异告警，确保错误修复不静默改写独立下游事实。

## 范围

- 实现采购单编辑/取消、采购价格变化、QC 更正、入库冲销和退供应商操作的影响预览；
- 预览返回订单号、BOM 版本、采购/到货/QC/入库数量、价格/金额、库存、应付来源、状态变化和人工复核风险；
- 对已确认入库或已生成应付来源的更正，使用冲销、调整或退货新事实，不直接更新历史事实；
- 实现采购不足、超收、QC 不合格、数量差异、价格变化、应付来源差异及负库存风险告警；
- 保留操作执行人、时间、原因、备注与变更前后值，并接入既有审计日志；
- 定义可复用的 `409 VERSION_CONFLICT`、`422` 业务错误和下游事实保护规则。

## 非范围

- 财务已确认应付后的付款冲销、核销与会计处理；
- 生产退料、成品退货和跨模块通用告警中心完整 UI；
- 供应商税费、运费和价格审批规则。

## 验收与验证

1. 存在已入库或应付来源时，采购单不可直接取消；接口返回需采取的退货/冲销动作。
2. 更正请求先提供影响预览；确认后在同一事务中重算允许派生值或创建新事实，不静默覆盖历史记录。
3. 退货/冲销后库存不会为负，应付来源产生可追溯的冲销或待复核差异。
4. 超收、采购不足、QC 不合格和价格/数量差异可按订单与单据查询，并不因告警自动阻断允许继续记录的业务。
5. API 集成测试覆盖下游保护、预览、冲销、审计和并发版本冲突。

## 决策记录

该任务只处理本纵向链路的回退。财务确认后的会计处理仍由财务链路实现，不能在此任务自行假设。
