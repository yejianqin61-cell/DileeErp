# 0821-02 BOM 至应付来源链路任务

本目录交付 `BOM -> 采购 -> 来料 QC -> 原料入库 -> 应付来源` 的纵向实现链路。前序 `0821-01` 已提供确认销售单、人工 `order_no`、BOM 来源版本、认证、RBAC、审计与 API 契约；本批不得重建这些能力。

执行前阅读 [BOM -> 采购 -> 来料 QC -> 原料入库 -> 应付来源实现设计](../../design/bom-procurement-inbound-qc-payable-chain-implementation-design.md)。每项任务认领和完成时必须更新任务状态、每日开发日志和编码路线图对应状态。

## 依赖顺序

```text
01 版本化表单与 BOM 明细
  -> 02 采购基础资料与 Schema
  -> 03 采购单与分批到货
  -> 04 来料 QC
  -> 05 原料入库、库存事实与应付来源
  -> 06 退货、冲销、影响预览与告警
  -> 07 前端纵向链路
  -> 08 集成与浏览器验收
```

`06` 可在 `05` 稳定后实施；`07` 可在 `03` 开始并行制作页面骨架，但只可在 `06` 后宣告链路可用。任何新业务口径先进入设计文档或 `docs/memo/`，不得以临时代码替代决策。
