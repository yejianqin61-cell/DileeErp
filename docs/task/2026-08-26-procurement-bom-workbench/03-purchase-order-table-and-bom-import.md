# 03 - 采购单表格与 BOM 表明细带入

**What to build:** 采购员在采购模块选择销售单和对应 BOM 表创建采购单。系统询问是否带入 BOM 表明细；带入时生成可继续编辑的采购行，不带入时创建空表。采购行以名称、型号、数量、单位和单价组成的表格维护，并可自由增删行。

**Blocked by:** 01 - 唯一可编辑 BOM 表 API; 02 - 采购模块 BOM 表格工作区.

**Status:** ready-for-agent

- [ ] 采购单始终绑定销售单、订单号和该销售单唯一 BOM 表。
- [ ] 操作员可选择带入或不带入 BOM 表行。
- [ ] 两种路径均支持增删改采购行并保存为草稿。
