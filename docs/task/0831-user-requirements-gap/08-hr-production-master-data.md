# 08 — 人事与生产基础资料字段治理

**What to build:** 完成人事字段、员工类型、离职状态、考勤时间、绩效入口，以及生产工序池和加工地点池的端到端治理。

**Blocked by:** #7、#8

**Status:** implemented — pending browser and integration acceptance

- [x] 员工支持筛选、编辑、入职/离职日期和原子化离职状态转换。
- [x] 员工类型由后端和前端共同限制为车间/非车间，不能提交自定义值。
- [x] 考勤支持日期、上下班时间及时间顺序校验；绩效可从登记流程新增类目。
- [x] 工序池和加工地点池有启用、停用、恢复、编辑和列表入口，生产单只能引用池中启用项。
- [x] 生产单保存工序/地点快照，后续主数据修改不改写历史单据。
- [ ] API、数据库约束和页面候选项保持一致，并补齐回归测试（需真实 PostgreSQL/浏览器验收）。

**Evidence:** 人事页面提供筛选、编辑、日期字段、导入导出及部门/岗位池入口；生产基础资料服务校验员工类型、组织关系、考勤时间和工序/地点有效性，控制器已对工序、加工地点和计价写操作启用管理员保护；相关 HR、生产主数据单元测试均通过。
