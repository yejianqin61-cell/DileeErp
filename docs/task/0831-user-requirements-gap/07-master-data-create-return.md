# 07 — 基础资料新增返回体验

**What to build:** 任意业务表单中的新增类目操作都能打开子表单；保存后返回原表单，保留已填写内容，并立即选中新建类目。

**Blocked by:** #7、#8

**Status:** ready-for-agent

- [ ] 客户联系人、供应商、物料、单位、部门和岗位均可从调用表单快速新增。
- [ ] 绩效类目、质检项目、送检项目等业务字典也有明确新增入口或统一维护入口。
- [ ] 子表单关闭或保存失败时，父表单值不丢失；保存成功后选项无需整页刷新即可出现。
- [ ] 新建记录自动选中，重复打开不会产生重复选项。
- [ ] 已被引用的类目只能停用/恢复，不允许破坏历史单据。
- [ ] 页面测试覆盖嵌套弹窗、取消、校验失败和成功返回。
