# 03 — 采购到货、质检、入库批次状态链

**What to build:** 以收货批次为唯一链路身份，自动创建来料质检任务，质检通过后才允许原料入库，并支持可审计的草稿、过账和冲销。

**Blocked by:** 02 — 采购单整单批次工作区

**Status:** ready-for-agent

- [ ] 每次有效到货只生成一条 pending 质检任务，重复请求不重复生成。
- [ ] 同一采购单可维护多个收货、质检和入库批次，列表均显示采购单号及批次序号。
- [ ] 质检数量分配满足送检、合格、条件接收和不合格的平衡约束。
- [ ] 只有允许入库的质检数量可创建原料入库；超量请求返回稳定业务错误。
- [ ] 入库状态支持 draft、posted、reversed 或等价状态，过账后只能冲销回退。
- [ ] API 集成测试覆盖重复请求、部分合格、非法回退和并发更新。
