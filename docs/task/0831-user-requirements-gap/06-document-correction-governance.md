# 06 — 全站单据草稿、确认与受控更正

**What to build:** 统一各业务单据的草稿编辑、确认、过账、冲销和回退规则；下游已有事实时禁止静默覆盖，所有更正保留原因和审计记录。

**Blocked by:** 02、03、04、05

**Status:** ready-for-agent

- [ ] 销售单、采购单、BOM、到货、质检、入库、生产单、领料和财务/工资单据都有明确状态和可用动作。
- [ ] 草稿可编辑或逻辑删除，确认/过账后只能通过受控更正、调整或冲销处理。
- [ ] 状态转换经过统一校验，非法转换返回稳定错误，不写入部分数据。
- [ ] 影响下游的修改保存前提供影响预览，包含受影响单据、库存/金额/状态变化和风险。
- [ ] 更正记录包含操作人、时间、原因、来源单据和变更前后值。
- [ ] API 和页面回归覆盖无下游事实、已有库存事实、已有付款/收款三类场景。
