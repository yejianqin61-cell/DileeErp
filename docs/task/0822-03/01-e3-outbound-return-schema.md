# Task 01：E3 出库与客户退货数据模型

## 目标

新增成品出库单、客户退货单及库存事实来源关系。

## 实施要求

- 新增 `FinishedGoodsOutbound`、`CustomerReturn`，包含 `order_no`、销售单/生产单、单位/产品快照、数量、状态、物流/签收资料、附件、幂等键、风险原因、审计和软删除字段。
- 为 `InventoryFact` 增加出库与客户退货来源关系，保持成品和不良品分类隔离。
- 增加状态、订单、来源和幂等索引/唯一约束，并创建 Prisma 迁移。

## 完成标准

Prisma generate、迁移 SQL 和类型检查通过，既有 E2 原料/成品入库行为不回归。
