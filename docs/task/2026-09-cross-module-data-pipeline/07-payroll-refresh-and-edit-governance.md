# 07 — 工资台账刷新与跨模块编辑治理

**What to build:** 让生产工资来源可靠进入工资台账，并统一销售、采购、质检、入库、财务单据的草稿编辑、受控回退和快照治理。

**Blocked by:** 02 — 采购与应付管线；04 — 生产日报与工资来源；05 — 生产完工；06 — 成品与应收管线

**Status:** ready-for-agent

- [ ] 工序员工日报保存后立即更新生产工资来源，草稿工资台账自动刷新生产工资金额。
- [ ] 已确认、部分支付和已支付台账不被静默修改；来源变化时显示过期状态。
- [ ] 已确认台账回退到草稿后可重新结算；已支付差额通过工资调整单处理。
- [ ] 按姓名生成台账时，重名返回候选并要求选择具体工号；界面始终显示姓名、工号和员工类型。
- [ ] 销售单确认后可编辑非核心字段；存在下游事实时核心字段必须先回退下游。
- [ ] 采购单有到货后锁定订单号、BOM、物料、单位和计划数量，只开放非事实字段。
- [ ] 已确认/过账/完成单据的修改、回退、冲销、金额覆盖均要求原因、权限和审计。
- [ ] 页面操作入口与后端状态一致，所有草稿支持编辑/删除，事实记录使用更正/冲销。
- [ ] 覆盖日报变更刷新台账、重名员工、核心字段锁定、草稿编辑、状态回退、冲销和权限测试。
