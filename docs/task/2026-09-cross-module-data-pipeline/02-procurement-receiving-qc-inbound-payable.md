# 02 — 采购到货、来料质检、原料入库与应付管线

**What to build:** 让采购单按明细分批到货，并将每个到货批次完整串联到唯一来料质检、分批原料入库和供应商应付/付款核销。

**Blocked by:** 01 — 统一物料类型、库存类别和历史数据约束

**Status:** ready-for-agent

## 增量修复记录（2026-09-03）

- 修正到货完成与关闭到货的状态机矛盾：达到计划量后，在真正关闭前仍可从采购工作台进入关闭动作；关闭后批次修改和撤销均被拒绝，并保留超单标记。
- 本次只修复该状态机缺口；本任务其余端到端验收项仍未标记完成。

- [ ] 采购单按每个明细累计到货量判定完成；达到或超过计划量时标记超单。
- [ ] 所有明细达到计划量后才能关闭到货；关闭后禁止继续登记到货。
- [ ] 撤销无下游事实的到货批次后，采购单按剩余有效到货量恢复为 `ordered`、`partially_arrived` 或 `arrived_complete`。
- [ ] 到货成功在同一事务内创建唯一来料质检记录和待确认应付来源。
- [ ] 同一到货批次不得创建第二条有效质检；分次检验累计更新原记录。
- [ ] 只有合格/条件接收数量可建立原料入库；同一批次支持多个入库草稿。
- [ ] 入库草稿可编辑、删除，过账后只能冲销；任何回退都检查下游事实。
- [ ] 到货应付按本批到货数量乘采购单价生成；金额覆盖必须填写原因。
- [ ] 应付确认后才可核销；付款过账必须至少核销一条应付，禁止无分配过账。
- [ ] 按批次和采购单汇总展示到货、质检、入库、应付和付款状态。
- [ ] 覆盖多批到货、超单、撤销恢复、重复质检、部分入库、应付差异、分批付款和冲销的端到端测试。
