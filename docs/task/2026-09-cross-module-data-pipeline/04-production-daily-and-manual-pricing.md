# 04 — 生产日报唯一聚合与人工计价

**What to build:** 将工序日报和工序员工日报收敛为生产单/工序/日期维度的可靠日汇总，并用人工填写的单价生成工资来源。

**Blocked by:** 01 — 统一日报唯一性和历史清理规则

**Status:** ready-for-agent

> **口径更新（2026-09-12，覆盖下方 9–11、15 行）**：员工日报改为**允许同一员工同日同工序多条**（支持复选、可混合计薪方式、可不同单价），每条独立成行、独立计薪；不再做同键累加、不再限制单一计薪方式、也不再因“目标日期已存在同键记录”而拒绝更正。工时统一按小时录入（`duration_hours`），落库仍为分钟，历史金额不重算。下方勾选项保留为历史验收口径，实际以本条为准。

- [ ] 同一生产单、同一工序、同一天只能有一条工序日报，重复登记累加完成数量。
- [ ] 同一生产单、同一工序、同一员工、同一天允许多条员工日报（可混合计薪方式），每条独立计薪。
- [ ] 更正日报要求原因和版本校验；同一员工同日同工序的第二条日报不再被拒绝，历史日报金额不因单位切换被重算。
- [ ] 计件必须填写件数，计时必须填写时长；单价必须由人工填写，不读取工序标准价。
- [ ] 日报保存、修改、删除均同步生产工资来源，并重算差异/超单告警。
- [ ] 页面按生产单 → 工序隔离，支持日期切换、计划数量/超单表头展示和当日员工总薪资。
- [ ] 覆盖同日累加、同一员工多条日报、混合计薪方式、人工单价、并发版本、删除重算和工资来源同步测试。
