# 06 — 成品 QC、成品库存、出库与应收

**What to build:** 将生产完成或外加工回厂的成品串联到分批 QC、成品入库、成品出库和应收收款，并保护下游事实一致性。

**Blocked by:** 03 — 库存事实与仓库过账；05 — 生产完工条件

**Status:** ready-for-agent

- [ ] 已检验合格/条件接收数量可先分批成品入库，未检验和不合格数量不可入库。
- [ ] 同一 QC 记录支持多次入库，累计数量不得超过可入库数量。
- [ ] QC 存在成品入库草稿或过账事实时禁止直接更正；必须先删除或冲销下游。
- [ ] 成品入库过账写入库存事实，冲销写入反向事实并校验库存。
- [ ] 成品出库过账校验库存和销售单价；没有销售单价时拒绝过账。
- [ ] 每个出库批次自动生成唯一草稿应收来源；收款过账必须核销应收。
- [ ] 出库、发货、签收、退货和冲销状态可追踪，所有更正记录原因。
- [ ] 覆盖厂内完成、外加工回厂、部分 QC、分批入库、库存不足、应收生成和收款核销测试。
