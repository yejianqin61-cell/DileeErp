# 01 — 统一业务约束与历史日报清理

**What to build:** 建立跨模块共享的物料、库存和日报数据约束，并在唯一性约束上线前安全处理历史重复日报。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] BOM 和采购明细后端只接受启用的 `raw_material`，成品只能进入成品链路；BOM 外采购物料必须记录新增原因。
- [ ] 原料入库接口强制使用 `raw_material` 库存类别，非法类别被拒绝。
- [ ] 盘点工序日报和员工日报重复业务键，保证数量、时长、金额合并后守恒。
- [ ] 同一员工同工序同日同时存在计件和计时的数据不自动合并，形成可处理异常清单。
- [ ] 合并后的旧记录软删除并保留合并关系、操作人、时间和原因。
- [ ] 清理完成后增加并验证防重复约束或等效事务门禁。
- [ ] 提供重复请求、并发写入、非法物料类型和非法库存分类的 API/数据库测试。
