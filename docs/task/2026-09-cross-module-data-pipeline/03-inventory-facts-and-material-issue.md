# 03 — 原料库存事实与生产领料

**What to build:** 统一原料库存余额口径，并让生产领料、退料、报废和冲销严格通过库存事实改变余额。

**Blocked by:** 01 — 统一物料类型、库存类别和历史数据约束

**Status:** ready-for-agent

## 增量修复记录（2026-09-03）

- `90fc889 fix: serialize raw material inbound edits` 保护原料入库草稿与库存事实边界：编辑不会直接改变库存余额，且并发编辑在 QC 来源锁内重新校验累计可入库量。
- 已通过 API 构建和原料入库服务回归测试；真实 PostgreSQL 并发验收仍待配置测试数据库。
- `57040cb fix: post current raw material inbound draft` 过账只使用锁内最新入库草稿数量写入库存事实，避免草稿修改与过账并发时库存金额/数量使用旧快照。
- 本轮补强：退料/报废过账在读取来源领料可处分数量前，按来源领料明细获取事务级 advisory lock，避免同一来源并发分配导致累计数量越界；API 构建和 `git diff --check` 已通过。

- [ ] 库存余额按物料和单位全局汇总，订单号仅用于流水追溯，不做订单预留。
- [ ] 只有原料入库过账、生产领料过账、退料、报废及反向事实改变原料库存。
- [ ] 禁止直接编辑库存余额和无来源手工调整。
- [ ] 领料预览展示 BOM 参考量、当前库存、采购到货/未入库、累计领用和生产未领用量。
- [ ] 过账前后均校验库存不足、单位一致、幂等键和并发冲突。
- [ ] 退料和报废只能引用已过账领料明细；冲销必须校验后续事实和库存余额。
- [ ] 仓库总览、采购库存比较和生产领料使用同一库存查询口径。
- [ ] 覆盖多订单共用物料、单位隔离、负库存、并发过账、退料、报废和冲销测试。
