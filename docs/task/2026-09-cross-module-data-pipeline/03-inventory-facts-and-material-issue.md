# 03 — 原料库存事实与生产领料

**What to build:** 统一原料库存余额口径，并让生产领料、退料、报废和冲销严格通过库存事实改变余额。

**Blocked by:** 01 — 统一物料类型、库存类别和历史数据约束

**Status:** ready-for-agent

- [ ] 库存余额按物料和单位全局汇总，订单号仅用于流水追溯，不做订单预留。
- [ ] 只有原料入库过账、生产领料过账、退料、报废及反向事实改变原料库存。
- [ ] 禁止直接编辑库存余额和无来源手工调整。
- [ ] 领料预览展示 BOM 参考量、当前库存、采购到货/未入库、累计领用和生产未领用量。
- [ ] 过账前后均校验库存不足、单位一致、幂等键和并发冲突。
- [ ] 退料和报废只能引用已过账领料明细；冲销必须校验后续事实和库存余额。
- [ ] 仓库总览、采购库存比较和生产领料使用同一库存查询口径。
- [ ] 覆盖多订单共用物料、单位隔离、负库存、并发过账、退料、报废和冲销测试。
