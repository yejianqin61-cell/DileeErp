# 05 — 生产单工序追加与完工强校验

**What to build:** 允许进行中的生产单继续添加工序，并在用户点击完成生产时用后端事务校验所有生产条件。

**Blocked by:** 04 — 生产日报和工资来源口径

**Status:** ready-for-agent

## 增量修复记录（2026-09-03）

- `980f02c fix: serialize production operation additions` 将进行中生产单的工序追加校验和创建收进事务，并锁定生产单，避免并发请求重复工序或重复顺序；继续保留草稿/进行中可追加、完工后禁止追加的状态边界。
- 已通过 API 构建和新增重复工序回归测试；真实 PostgreSQL 并发验收仍待配置测试数据库。
- 本轮补强：工序编辑和取消共用生产单状态门禁，完工或关闭后的生产单不再允许改变工序结构；完整单元测试 87 项通过。

- [ ] 草稿和进行中的生产单均可添加有效工序，工序顺序和单位唯一且合法。
- [ ] 追加工序后，生产单工序列表、工序日报入口和进度统计立即同步。
- [ ] 厂内生产单完成前校验所有未取消工序累计完成量达到计划量。
- [ ] 存在未处理日报差异或超单告警时禁止完工；告警确认后允许继续。
- [ ] 外加工生产单完成前校验回厂交接累计量达到计划量，发出不等于完成。
- [ ] 完工后禁止新增工序和生产日报，但允许成品 QC、入库和出库继续流转。
- [ ] 覆盖进行中追加工序、缺工序日报、未处理告警、外加工短收和重复完工请求测试。
