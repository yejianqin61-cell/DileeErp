## 本批已定（实施者不得重开）

| 决定 | 内容 | 出处 |
|---|---|---|
| 缺口题范围 | 真缺口 10 + 干扰 10 | 用户 2026-11-26 |
| 轮数 | 3 轮 | 用户 2026-11-26 |
| 用例总数 | P1 的 70 条原样，加 1 条目录问法，加 20 条缺口题 | 本批决定 |
| 步数中位数 | 每条先取三轮中间值，再取各条的中位数，下标 `floor(n/2)`（与 P1 同算法） | 本批决定 |
| 判据一 | **只看 P1 那 70 条**，中位数 ≤ 2 | 计划 R-12 |
| 判据二 | 全部 91 条三轮全过 | 计划 R-12「黄金集保持全部通过」 |
| 判据三 | P1 那 70 条里带失败码的用例轮次占比 ≤ 1/70 | 计划 R-12「不回升」，P1 为 1.4% |
| 漂移率 | 真缺口题放行的声明中，最近邻与题集标注不一致的条数 ÷ 放行声明总条数 | 设计 §5.3 |
| 误报率 | 干扰题中出现放行声明的用例轮次 ÷ 干扰题用例轮次 | 本批决定 |
| 密钥 | `DEEPSEEK_API_KEY` 只从环境变量来，只检查有没有，从不打印、不写进任何文件 | 阶段 2 惯例 |
| 注释 | 新写代码不写散文注释 | 设计 §7.2 |
