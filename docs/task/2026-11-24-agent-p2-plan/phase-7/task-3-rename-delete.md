# 任务 3：重命名与删除

<task-brief>

## 1. 在哪里

- **阶段 7 会话能像样地用**。
- **本任务推进 R-9**：历史弹窗里能改名、能删除，标题以手动名优先。
- **开工前提**：任务 1 已提交。**后续**：任务 6。

## 2. 要知道的

**先读**

- `apps/web/components/agent/agent-history-dialog.tsx`：列表结构与脚注文案。
- `apps/web/app/agent/page.tsx`：`loadHistory`、`switchSession`、新建对话。
- `apps/web/lib/agent-chat.ts`：`AgentSessionSummary`、`sessionTitleFromRuns`。
- `apps/web/components/ui`：确认框用现成哪一个。

**已定**

- 标题 = 服务端 `title`，为 `null` 时用首个问题。
- 改名在列表项内就地输入，回车保存、Esc 取消；空白不提交。
- 删除先弹确认框，文案说明「删除后你看不到这个会话」。
- 删掉当前会话：回欢迎页并清该用户的本地会话缓存。
- 接口失败：弹窗内显示服务端消息，列表不变。运行中整个历史入口仍禁用。
- 脚注改为「仅本人可见。」或「只显示最近 20 个会话。」，去掉「后端暂无接口」。

**边界与接缝**

- 动弹窗、顾问页、`agent-chat.ts`、新测试 `apps/web/test/agent-history-actions.test.tsx`。接缝：渲染页面，替身同现有页面测试。

**运行**

- `npm run test:unit --workspace=@dilee/web`，`npm run typecheck`

**可能卡住**

- 现有测试断言了旧脚注：只改那一条期望，提交说明写明。其他现有断言要改就停下上报。
