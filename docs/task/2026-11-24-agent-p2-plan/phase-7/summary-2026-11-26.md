## 2. What it means

会话层到此和常见聊天产品的基本操作对齐，且服务端仍是唯一真源：改名与删除落库，分支只是本机对同一批轮次的看法。
代价是分支不跨设备，在别的电脑上继续问时，上下文按直线历史给模型。

上线影响：迁移 `20261126090000_agent_session_title` 给 `agent_sessions` 加两个可空列。
按现有发布探针的要求，状态账号已有该表的更新权限，不需要新授权；本次没有用受限账号验过。

验证规模：全套 `npm run test` 退出码 0（部署门禁 98、API 3260、实验装置 35、web lib 457、web 组件 1537）；web 构建通过。
浏览器端到端三个 spec 共 13 条在空库上一次全过，环境是独立的一次性 PostgreSQL 加假模型，跑完已删除。
长答案用例本次最长任务 0 毫秒。深色主题截图人工看过，对话与历史弹窗文字可读。

与简报的偏差：删除确认框用 `Dialog` 而非现成 `AlertDialog`（后者一渲染就抛错）；
任务 1、2、5、6 的用例先写后实现，但没有逐条单独跑出红。
