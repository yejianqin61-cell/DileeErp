## 本批已定（实施者不得重开）

| 决定 | 内容 | 出处 |
|---|---|---|
| 重命名与删除 | 后端真做：标题字段、软删除、一条迁移 | 用户 2026-11-26 |
| 分支上下文 | 提问时带上本轮上下文用哪几轮；服务端校验归属与档位，**不存分支结构** | 用户 2026-11-26、设计 §7.1 |
| 主题与语言 | **只做顾问页**。主题默认跟随系统，语言默认中文，可手动切；侧栏与其他页面不变 | 用户 2026-11-26 |
| 自动标题 | 沿用现状：取首个问题，客户端按快照算；服务端只存手动改的名字 | 本批决定 |
| 分支存放 | 只存轮次号的父子关系，在浏览器本地；换电脑看到的是按时间排的直线历史 | 本批决定 |
| 草稿存放 | 普通账号存 IndexedDB；老板、财务账号只存 `sessionStorage`（刷新不丢，关页即丢） | 本批决定 |
| 退出登录 | 清缓存的问答与草稿；**保留**分支关系（只有轮次号）与主题语言设置 | 本批决定 |
| 不翻译 | 服务端返回的文字、执行步骤的工具名称、单据类型、回答内容 | 本批决定 |
| 许可与注释 | 从 chat-demo 搬的文件加许可头（写法同阶段 6）；其余不写注释 | 设计 §7.2 |
