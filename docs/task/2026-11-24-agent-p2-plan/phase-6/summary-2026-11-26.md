## 2. What it means

阶段 6 的验收在本机达成。`/agent` 首屏 JS 从 146 kB 到 180 kB，图表库不在首屏。

显示上的行为变化：行首的裸 HTML 与同一行后续文字整体按原文显示，旧解析器会继续解析其后的粗体；
`__文字__` 现在是粗体。安全口径不变：裸 HTML 只当文本，只有 `http(s)` 成链接，图片不加载。

耗时数据：未加按段缓存时 3 次为 0、131、65 毫秒；加后 5 次为 0、0、0、0、59 毫秒。
中途有一次 1.2 小时的失败，系统日志显示那段时间电脑在待机，不计入。

验证规模：全套 `npm run test` 退出码 0，其中 API 3246、实验装置 35、web lib 457、web 组件 1503；web 构建通过。
web lib 比阶段 5 少 13 条，是随手写解析器删除的测试，对应断言改由解析与渲染用例覆盖。

提交历史里有两处当时是红的、随后单独修复：任务 1 提交时类型检查失败；公式节点修复提交里测试文件语法错误。
