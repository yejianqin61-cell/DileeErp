# T4 历史快照回填与未归位清单

## 1. 这份任务在哪

- **Phase 1 科目有了身份证**，目标是改一个科目名之后所有报表数字一个都不变。
- **本任务把已有的历史文本快照补上科目主键，并留下归不上的清单**：凭证分录只回填了一半，期初完全没回填。
- **开始于**：T1 给科目加不可变编码、T3 期初余额落科目主键。**后续等它**：改名回归用例。

## 2. 开发前需要知道什么

**先读**

- `apps/api/prisma/migrations/20261109130000_finance_governance_r3/migration.sql` — 上一轮回填只做 `subject_id`，`business_subject_id` 没做，且用的是「唯一同名」判据。
- `apps/api/src/modules/finance/voucher.service.ts` 的按名解析段 — 回填之后新写入走的是同一套判据。
- `apps/api/src/modules/finance/opening-balance.service.ts` 的整批替换 — 回填要能兼容它的软删占位。

**已定**

- 回填判据只有一条：唯一同名才算归上，歧义与查不到一律留空。这条已在上一轮定过，不重开。
- 未归位清单写成一条审计事件，字段含四类计数：凭证业务科目、凭证辅助科目、收支类目、期初余额。
- 回填可重复执行，第二次跑不改变任何行。

**边界与缝**

- 触及迁移与审计事件。不碰业务逻辑。
- 缝：既有迁移守卫测试入口。不新增缝。

**运行**

- `npx prisma migrate status`
- `node --test apps/api/test/unit/accounting-subject-migration.test.cjs`
- `npx tsc -p apps/api/tsconfig.json --noEmit`

**未知**

- 本机开发库的凭证与期初都是空表，回填跑不出真实效果。验收靠迁移幂等性与清单里四类计数都存在，不靠行数。

## 3. 流程

1. 读上面三个文件，用一句话复述本任务。
2. 写迁移：回填凭证的辅助科目主键。
3. 同一迁移里回填期初余额的科目主键。
4. 统计四类未归位行数，写一条审计事件。
5. 确认迁移可重复执行。
6. 加守卫测试：回填判据是唯一同名，清单字段齐全。
7. 跑迁移状态、测试与类型检查。
8. 提交。
