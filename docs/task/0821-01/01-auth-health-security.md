## 目标

完成数据库受控会话认证、RBAC 权限和健康检查的真实 PostgreSQL/浏览器验证，使后续业务 API 只能在可信用户身份下执行。

## 范围

- 启动 PostgreSQL、生成 Prisma Client、执行现有迁移并建立可重复的最小初始管理员初始化方式；
- 完善健康检查：分别检查应用与数据库，数据库不可用时返回符合全局错误契约的失败结果；
- 使用 Argon2id 存储密码；管理员创建用户及重置密码执行密码长度、弱口令和确认校验；
- 实现安全会话：随机令牌哈希存储、`httpOnly`/`sameSite=lax` Cookie、生产环境 `secure`、登录会话轮换、退出/停用/重置后的会话失效；
- 实现登录限流或短时锁定，统一登录失败提示和安全审计；
- 实现并验证 RBAC：管理员、用户-角色关系、角色-模块授权、`sales` 模块授权与实时撤销；
- 提供真实浏览器登录、会话恢复、退出和 `401` 处理的最小前端入口。

## 非范围

- 自助注册、找回密码、短信、验证码、MFA、外部 SSO、移动端认证；
- 字段级、行级、审批或临时权限；
- 客户和销售业务表。

## 验收与验证

1. 新建管理员可登录、刷新后通过 `/auth/me` 恢复会话、退出后同一会话失效。
2. 错误密码、未知账号与被停用账号均返回相同语义的 `401`，不泄露账号存在性。
3. 密码、原始会话令牌和密码哈希不出现在 API 响应、日志或审计详情中。
4. 停用用户、重置密码或撤销权限后，下一次请求立即生效。
5. 未登录返回 `401`；无 `sales` 权限的用户访问销售资源返回 `403`；管理员可访问已开放模块。
6. 数据库可用/不可用时健康检查的行为、状态码和 JSON 契约有自动化测试。
7. PostgreSQL 空库重复执行迁移和初始化不产生重复或无归属审计数据。

## 决策记录

- 认证采用数据库会话而非 JWT；原因是本地 Web ERP 需要立即撤销与最小安全复杂度。
- 不开放注册；账号生命周期属于管理员职责。
