# 0821-01-03 客户池后端 API

## 状态

已完成（PostgreSQL 集成验证待环境恢复）

## 认领

负责人：Codex
开始日期：2026-08-21

## 目标

实现受 `sales` 权限保护的客户与联系人 API，作为销售单创建的真实上游。

## 关联决策

- `docs/design/0821-01-initial-order-chain-delivery-plan.md`
- `docs/design/global-api-contract.md`
- `docs/design/sales-module-design.md`

## 范围

- 实现客户列表、详情、创建、编辑、停用和逻辑删除 API；
- 实现客户联系人新增、编辑、默认联系人和停用 API；
- 统一使用分页、查询、审计、软删除、权限守卫、`ApiError` 和错误契约；
- 将客户唯一冲突转换为稳定业务错误码；
- 为下游销售单提供客户及联系人快照读取能力。

## 非范围

- 销售单、BOM、导出、应收或客户报价；
- 未在销售设计中确认的客户评级、信用额度和自动提醒。

## 验收与验证

1. 仅具备 `sales` 权限的登录用户可以操作客户；无权和未登录分别返回 `403`、`401`。
2. 重复客户名称/代码返回稳定冲突码，且不产生半条数据。
3. 已被销售单引用的客户不能以破坏引用的方式删除，只允许停用或受控逻辑删除。
4. 客户联系人可被维护且默认联系人规则一致。
5. 每一次写操作保留操作人、时间、前后变化和原因（需要原因的操作）。
