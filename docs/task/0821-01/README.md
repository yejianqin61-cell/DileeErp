# 0821-01 初链路任务

本目录的任务按依赖顺序交付“登录 -> 客户 -> 销售单/订单号 -> 销售确认 -> BOM”的真实前后端链路。

执行前先阅读 [0821-01 初链路打通计划](../../design/0821-01-initial-order-chain-delivery-plan.md)。每个任务开始和完成时均按项目宪章更新任务状态与每日开发日志。

## 依赖顺序

1. `01` 是运行与认证安全门槛。
2. `02` 固定销售域权限和共享领域基础。
3. `03`、`04`、`05` 依次构成后端订单链路。
4. `06` 在后端链路可用后替换前端占位。
5. `07` 对完整浏览器链路做验收。

不得跳过前置任务；发现新的业务规则时，先更新设计文档或 memo，再开始实现。
