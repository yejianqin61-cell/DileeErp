## 目标

移除当前前端的演示数据和模块占位，用真实 API 打通登录、客户、销售单、订单确认和 BOM 来源查看的 Web 操作。

## 范围

- 登录页、会话恢复、退出和 API `401/403/422/409` 错误呈现；
- 客户与联系人列表、创建、编辑、停用页面；
- 销售单列表、草稿表单、订单号冲突提示、详情、确认和影响预览页面；
- BOM 创建入口、详情和销售版本来源展示；
- 删除演示数据适配器、演示公告、已开放页面中的占位组件及伪业务表格；
- 未开发模块采用统一真实空状态和禁用导航说明，不显示演示数据；工作台仅展示真实 API 数据或空状态；
- 复用既有 UI token、TanStack Table 和 React Hook Form。

## 非范围

- 采购、生产、仓库、财务和人事的真实业务操作；
- 移动端、离线和复杂仪表盘；
- BOM/QC 可配置字段管理界面。

## 验收与验证

1. 不登录不能进入受保护业务页；登录后刷新仍保持会话，退出后返回登录页。
2. 可通过页面完成客户创建、销售单创建、订单号冲突查看、确认、BOM 创建及来源查看。
3. 已开放页面无“演示数据”“占位”“待确认”等伪功能文案或假数据。
4. API 失败能显示对操作员有用的消息，不暴露技术栈或请求机密。
5. 在桌面浏览器常规尺寸下表单、表格、提示和按钮不重叠、无横向溢出。
