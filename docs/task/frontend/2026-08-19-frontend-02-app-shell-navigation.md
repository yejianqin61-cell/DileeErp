## 目标

实现适合厂内文员桌面使用的 AppShell、顶部栏、左侧导航、页面标题和面包屑。

## 范围

- 顶部栏：迪礼 ERP、演示环境提示、当前用户占位与退出入口占位。
- 左侧导航：工作台、生产、采购、财务、仓库、人事、客户池。
- 激活路由状态、中文导航标签、Lucide 图标和 hover/focus 状态。
- 主内容区和固定尺寸约束。
- `PageHeader` 与面包屑容器。

## 非范围

不接入真实登录、权限、退出 API；不做手机端折叠导航。

## 验收与验证

- 所有初始路由可通过导航访问，激活状态准确。
- 桌面宽度下导航和主要内容不重叠。
- 截图检查工作台及任一模块页的布局。
