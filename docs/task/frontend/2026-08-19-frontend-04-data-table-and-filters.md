# 前端任务 04：DataTable 与筛选容器

## 状态
待认领

## 依赖
前端任务 01、03。

## 目标

基于 TanStack Table 建立可复用的桌面数据列表、筛选容器和状态标签。

## 范围

- 类型安全的 `DataTable`，接收页面提供的列定义和数据。
- 表头、行高、排序交互、空状态和加载状态。
- `FilterBar` 容器及筛选控件布局。
- `StatusBadge`，仅接收标签/语义类型，不内置订单等业务状态值。
- 演示列表分页占位。

## 非范围

不接入后端分页、业务筛选字段或最终报表导出。

## 验收与验证

- 工作台和模块占位页可复用同一表格组件。
- 列定义变更不会要求改动表格内部业务代码。
- 长文本、无数据和加载状态不破坏表格高度。
