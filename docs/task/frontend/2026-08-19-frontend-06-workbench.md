# 前端任务 06：工作台占位页面

## 状态
已完成

## 依赖
前端任务 02、03、04、05。

## 目标

实现可供刘总和各负责人讨论的工作台，集中呈现已确认的订单推进、生产进度、应收应付和待处理事项视角。

## 范围

- 订单推进状态列表占位。
- 生产工序进度列表占位，并显式标记工序字段待车间确认。
- 应收应付列表占位，展示币种与原币金额。
- 待处理事项占位。
- 正常、空、加载、错误状态切换演示。

## 非范围

不实现真实统计、状态计算、自动提醒、订单详情或报表导出。

## 验收与验证

- 三个已确认管理视角全部可见且层级清晰。
- 演示数据不被表述为真实业务数据。
- 在 1366px 及以上桌面宽度截图检查可扫描性。
