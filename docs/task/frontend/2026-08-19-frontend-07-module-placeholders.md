# 前端任务 07：六模块占位页面

## 状态
待认领

## 依赖
前端任务 02、03、04、05。

## 目标

建立生产、采购、财务、仓库、人事、客户池的统一占位页面，用于逐个与模块负责人确认首屏入口和信息层级。

## 范围

- 路由：`/production`、`/procurement`、`/finance`、`/warehouse`、`/hr`、`/customers`。
- 每页包含标题、职责、建议首屏列表、主操作占位、演示数据提示、待确认事项和空状态。
- 使用公共 `DataTable`、`FilterBar`、`PageHeader`、`EmptyState` 等组件。
- 页面访谈提示链接到术语词典和模块说明。

## 非范围

不实现真实创建、编辑、删除、业务详情、最终字段或数据库关联。

## 验收与验证

- 六页导航可达且视觉结构一致。
- 每页展示内容只限于已确认的模块边界，不增加未确认业务规则。
- 页面作为访谈材料可回答“首屏看什么、主操作是什么、待确认什么”。
