# 前端任务 03：统一反馈与面板容器

## 状态
待认领

## 依赖
前端任务 01、02。

## 目标

建立空数据、加载、错误、详情、表单和附件等通用页面反馈/承载组件。

## 范围

- `EmptyState`、`LoadingState`、`ErrorState`。
- `DetailPanel`、`FormPanel`、`AttachmentPanel` 容器。
- 使用 React Hook Form 的通用表单容器和校验错误展示方式。
- 明确“演示数据”视觉提示组件。

## 非范围

不定义任一模块的最终字段、附件必传规则或提交 API。

## 验收与验证

- 每个反馈组件具备可读中文文案和稳定布局。
- 表单容器能展示校验失败而不依赖业务字段。
- 公共组件不 import 任何业务 feature。
