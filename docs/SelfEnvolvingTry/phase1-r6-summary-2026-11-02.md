## 2. 变化的含义

宿主受限入口新增 `production.read_employee_output_summary`。
它按订单、工序和员工返回每日分组及累计分组，并在宿主侧限制每组最多 100 行。
候选请求不再携带访问档位；有效档位来自宿主上下文，候选不能伪造 `full`。

订单 A 脱敏样例返回了以下事实：员工甲在 2026-10-30 产出 `12.0000`，
2026-10-31 产出 `8.0000`，累计 `20.0000`；员工乙累计 `5.0000`。
候选工具只把受限结果转换为 `QueryFact`，不连接 Prisma、SQL、网络或业务数据库。

独立门禁会重新枚举候选文件并计算 SHA-256，核对 Git 源码基线、能力声明、路径白名单、
候选代码能力和测试/权限回调。候选代码只允许 `node:crypto`、`node:util` 等已批准纯计算模块，
文件、网络、进程、动态模块加载和凭据访问都会被拒绝。

真实 Linux 纵切使用 `node:24.9.0-alpine`，验证了源码可读但不可写，验证态候选目录只读，
网络不可达，数据库/Cookie/用户令牌不可见。R-5 文件隔离探针也在同一轮真实通过。

## 3. 仍未完成

- 候选仍是阶段一待审产物，尚未写入活动 Tool Registry 或 Artifact Registry。
- 受限入口仍使用脱敏夹具适配器，尚未连接生产数据库或跨容器 RPC。
- 当前候选门禁回调由 Worker 测试提供；ERP 发布器尚未独立读取 Validator 报告并执行生产级重跑。
- `runCodingBatch()` 尚未迁移为在该 Linux 容器内启动完整 DSH Harness；本轮只在容器内执行候选纵切。
- 模型出口、生产容器编排、后代进程树清理和资源耗尽恢复仍需生产同型验证。
- `R-7 并行批次与可观察失败`、Artifact Registry、热重载、Query Agent 续跑和前端工作态仍未开始。
