## 这些变更意味着什么？

门禁不再只相信 Agent 声称“测试通过”：它要求候选中的 `tool.ts` 和 `tool.test.ts` 同时被冻结并进入哈希；Validator 报告的字节哈希必须与证据记录一致；新离线容器会先执行该 Builder 测试，再运行宿主固定样例与权限探针。Builder 无法在交付副本上继续写入，网络和数据库凭据也不可用。

并行不再只由模拟数组断言：真实模型批次在临时空目录中分别创建 `employee-output` 和 `employee-inventory` 的实现及测试。它记录两个重叠 Builder、两个后置 Validator，以及 Inventory 的一次原会话返工和复审。恢复 Builder 的 Activation 以会话 ID 绑定元数据，异步恢复也不会遗漏能力和角色。
