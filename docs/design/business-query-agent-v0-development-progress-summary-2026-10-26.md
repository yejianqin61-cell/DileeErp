## 2. 这意味着什么

线上版本 `738cd66213d8b53b48cf6db217e89dee87a3763c` 已运行在 `118.178.95.156`。
API 与 Web 进程均在线，内外网健康检查均返回数据库正常。

Agent 已使用独立的业务只读账号和 Agent 状态账号。
真实数据库证明了业务写入被拒绝，状态账号也不能读取业务表。
目前的 31 项 operation 均已登记并实现，其中 24 项面向 operational，7 项财务能力只面向 full。

用户可通过 `BUSINESS_QUERY_ENABLED=false` 关闭全部 Agent 路由。
关闭不会创建新 run 或调用模型，也不会删除 `agent_sessions`、`agent_runs` 与 `agent_run_events`。

## 3. 仍未完成

- 真实 operational 与 full 账号尚未对同一脱敏订单完成 DeepSeek 问答，所以两档真实输出还没有签核记录。
- 脱敏代表订单与既有页面的逐项对照尚未留档，所以 31 项查询的生产数据口径仍缺最终证据。
- 线上模型用量、响应耗时和结构化日志基线尚未记录，所以成本与性能没有真实基线。
- 关闭 Agent 后的线上业务连续性尚未做真实演练，所以回退路径仍缺运行记录。
- 联系人电话、地址的可见范围，以及公有模型或内网模型的企业数据路径仍未确认。
