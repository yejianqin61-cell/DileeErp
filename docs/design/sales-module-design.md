# 迪礼 ERP V1.0 销售模块初步设计

> 文档类型：业务/领域设计文档，不是开发任务文档。
>
> 状态：访谈中。本文仅记录已确认事实；待确认规则见 [销售模块集中待确认事项](../memo/0820-销售模块集中待确认事项.md)。

## 1. 设计目标

销售模块维护客户池、销售单和订单级产品信息。销售人员以 ERP 表单录入销售单，系统以 `order_no` 作为全流程身份证；物控依据销售单建立订单 BOM，采购、生产、仓库和财务再使用同一订单号追溯业务。

V1.0 不包含询盘、报价、样品单、英文合同和接单转化。销售单是本期订单业务的起点，并可按既有客户单模板导出 Excel。

固定原则：

- 一个订单 V1.0 只对应一款产品，销售单记录该产品的名称、规格、数量、交期及客户要求。
- 销售单必须关联客户，并生成或维护唯一 `order_no`；客户 PO/合同号作为参考字段，不能替代订单号。
- 物控从销售单读取订单要求并建立 BOM；销售单变更不得静默改写已建立 BOM、采购单、生产单、仓库或财务事实，必须展示影响预览和差异/复核提示。
- 销售单导出以受版本控制的 Excel 模板为准：ERP 录入字段映射到模板单元格，导出时保留模板的打印设置、合并单元格、公式、图片区域和版式。
- 模板字段、客户/产品业务类目和业务要求类型的可维护范围待确认；已使用的历史值必须保留快照并可追溯。

## 2. 已确认模板基线

首个模板来源：`example/销售单/DL260001-1 花色生产单-IS(FLOWER1 PO#32366-1).xlsx`。

已核实的模板特征：

- 单工作表：`32366-1 FLOWER1`；打印范围为单页 `A1:R56`，纵向，缩放 80%，含 114 个合并单元格。
- 页头包含工厂、客户单号、客户代码、下单日期、数量、品名规格、完工日期。
- 主体包含材料明细、工艺要求、包装明细、材料到货状态、制单、审核。
- 包含多款花色/伞头的名称、配色、条码与数量/打明细；总数量由 `SUM(K42:K56)` 公式汇总。
- 模板存在图片与版式内容。导出不是简单列表下载，必须按模板单元格映射生成可打印 Excel。

模板文件本身不等于数据库模型。销售表单保存结构化业务数据、模板版本和字段映射；导出服务按模板版本填充数据，不能将模板上的合并单元格或单元格地址硬编码为销售业务规则。

## 3. 初步业务链路

```text
客户池 -> 销售人员录入销售单（order_no） -> 导出客户模板 Excel
                                              |
                                              v
                                      物控建立订单 BOM
                                              |
                +-----------------------------+---------------------------+
                v                             v                           v
             采购单                        生产单                    后续出库/应收
```

销售单、导出文件、BOM、采购单、生产单、成品出库和应收来源均应保留订单号与内部关联 ID。

## 4. 初步对象与边界

| 对象 | 业务职责 | 已确认关系 |
| --- | --- | --- |
| 客户池 | 客户及联系人基础资料 | 销售单必须关联客户；具体字段待确认 |
| 销售单 | 订单级产品、客户要求和交付约定 | 一单一款产品，关联唯一订单号与客户 |
| 销售单产品信息 | 销售单中的产品名称、规格、数量、单位及客户要求 | 后续映射到 BOM、生产单和模板导出 |
| 花色/配色/条码明细 | 模板中多款配色产品的明细数据 | 是否每单必需及字段规则待确认 |
| 销售单模板 | Excel 模板文件、版本、字段映射、打印/导出约束 | V1.0 首个模板为花色生产单示例 |
| 导出记录 | 按模板导出的 Excel 业务文件 | 关联销售单、模板版本、操作人、时间和附件 |
| 订单 BOM | 物控根据销售单建立的物料需求表 | 关联销售单/订单；由物控模块维护 |

## 5. 销售单到 BOM 的联动原则

销售单是 BOM 的上游业务依据，但不自动生成通用 BOM：物控根据销售单中的产品、数量、材料、工艺、包装和客户要求建立订单 BOM。

销售单尚未关联 BOM 时，销售人员可按状态规则修改。已关联 BOM 后，修改前必须展示：受影响 BOM 版本、采购单、已入库数量、生产单、领料、成品入出库、应收来源及风险。确认后：

1. 未确认的 BOM 可按已确认规则更新或提示物控复核；
2. 已确认 BOM、采购、生产、库存和财务业务事实不被直接篡改；
3. 系统建立销售单与 BOM 的差异/复核提示，保留变更前后快照、操作人、时间和原因；
4. 导出销售单时可选择当前销售单版本，历史导出文件与模板版本继续可查。
