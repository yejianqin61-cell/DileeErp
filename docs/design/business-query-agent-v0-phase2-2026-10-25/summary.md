## 2. 意味着什么

模块已经「只差一把钥匙」：模型调用、工具循环、上下文、并发、观测、错误语义都是生产形态，
`AGENT_LLM_PROVIDER=deepseek` + `DEEPSEEK_API_KEY` 两条配置即从演示切到真实模型。
协议栈选了 AI SDK v7，DeepSeek 的报文解析、流式与 toolCall 往返都交给了它，本项目保住的
只有三件事：工具不在 SDK 里执行、答案才流式、错误只出稳定码。
