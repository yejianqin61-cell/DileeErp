# Task 6：浏览器恢复与取消证据

## 目标

用真实浏览器、真实本地 API 和 fake provider 走通两个用户可见流程：回答中刷新后恢复同一 run，以及回答中取消后落到稳定终态。

## 范围

- 新增一个 Playwright E2E 用例文件；沿用现有登录、页面 test id 和本地 API。
- 刷新场景只断言一个 `POST /runs`，并等待同一页面恢复为“已完成”。
- 取消场景点击页面原生取消按钮，并断言“已取消”。
- 用 `AGENT_FAKE_DELAY_MS` 保持足够的活动窗口；未提供登录凭据或延迟不足时跳过，避免把环境依赖伪装成产品失败。

## 不做

- 不新增页面逻辑、测试专用后门、用户账号或数据库结构。
- 不把 429、409、权限撤销伪装成 live browser 后端流；这些分别沿用已有 HTTP、组件和 reducer/transport 证据。

## 验收

- [ ] 刷新期间只有一次创建 run 请求，最终答案和完成状态可见。
- [ ] 取消后页面展示“已取消”。
- [ ] 在本地 fake provider 环境实际运行通过。
