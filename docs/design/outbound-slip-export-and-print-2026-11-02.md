# 出库单导出 Excel 与打印（成品出库单 + 领料单/补料单）

- 日期：2026-11-02
- 用户原话：「现在针对系统中的出库单，要支持导出 excel，支持打印」
- 同日拍板两件事：
  1. **两张都要**：成品出库单（导出 + 打印）、原料出库（领料单/补料单，只补打印，导出本来就有）；
  2. **逐张**：每行两个入口（打印 / 导出），不做「按筛选批量导出、一叠连续打印」。

## 1. 一条原则：纸面与导出件是同一份数据

后端各组装**一次**单据对象：

- 成品出库单：`FinishedGoodsOutboundExportService.buildDocument(id)` → `FinishedGoodsOutboundDocument`
  （`GET /finished-goods/outbounds/:id/slip-document` 返回它，`GET .../export.xlsx` 也用它渲染）；
- 领料单 / 补料单：沿用 2026-09 就有的 `GET /production/material-movements/:id/slip-document`
  （`MaterialSlipExportService.buildSlipDocument`，明细四个数量也在这里算）。

页面打印视图只渲染这份数据、不自算一遍数量。两份各拼一次，迟早出现「纸上有、屏幕上少一行」——
而仓库就是拿着这张纸跟司机/车间点货的。2026-10-29 那次「页面与纸面对不上」已经吃过一次这个亏。

## 2. 成品出库单（新增）

### 版式（A4 竖版，8 列）

| 区块 | 内容 |
| --- | --- |
| 标题 | `厦门迪礼伞业有限公司　【成品出库单】（状态）`——**草稿/已取消/已冲销把状态印在标题上**：一张"待出库"的单子被当成已发货凭据拿出去，比没有单子更糟 |
| 表头 3 行 × 4 组 | 出库单号 / 单据日期 / 状态 / 客户名称；订单号 / 生产单号 / 产品名称 / 规格型号；本批数量 / 发货日期 / 承运商 / 出库通知 |
| 明细表 | 序号 / 产品名称 / 规格型号 / 单位 / 数量 / 备注（出库单只有一行：一次出库 = 一个产品的一批数量，但排版与领料单同一块，对货时看同一位置） |
| 合计 | 本批数量 |
| 发货与签收 | 运单号 / 装箱单号 / 发票号 / 签收日期；签收凭证 / 备注 |
| 签字栏 | 仓库经办 / 承运人 / 客户签收 / 日期（空白供手签） |
| 页脚 | 制单人 + 打印时间（北京时间，带秒）：同一张单先后打两版时能看出哪份是新的 |

**不印单价与金额**：这张纸先到司机和客户手上，价格属于财务口径（应收在过账时单独生成，
看【应收 → 成品出库条目】）。空值一律印空格而不是 "-"：纸上的空格子要留给手写补（运单号常常发货时才填）。

### 导出与打印

- 导出：`GET /finished-goods/outbounds/:id/export.xlsx`，ExcelJS 渲染 A4 竖版（`fitToWidth: 1`），
  文件名 `迪礼ERP-成品出库单-<出库单号>.xlsx`；**这份 xlsx 本身就能直接打印**（纸上与屏幕打印件同版式）。
- 打印：仓库成品仓储页每行「出库单」→ 弹窗里是那张纸 → 「打印 / 另存 PDF」走浏览器打印
  （与记账凭证纸、跨行转账单同一做法：`@media print` 只留 `.outbound-slip-sheet`）。
- 任何状态都能出纸（草稿、已冲销也常要打一张留档），状态由标题表达。

## 3. 领料单 / 补料单（补打印）

- 版式照样例 `docs/samples/领料单-样例.xlsx` / `补料单-样例.xlsx` 与既有导出件：
  标题（含状态：草稿/待仓库出库/已冲销）、三行表头（补料单第 2 行「领料单位」在前、「领料工序」在后）、
  明细表、小计、备注。
- 领料单明细 10 列（含**配料 / 已领 / 本次领料量 / 余下数量**四个数量，与页面同源）；
  补料单 8 列（含留空的「图片」列 + 补领数量）。
- 入口：领料单列表页与生产单详情里的领料面板，每行「打印」；同一份 `slip-document` 数据，
  导出（已有）与打印不会分叉。
- 小计：领料单合计「本次领料量」，补料单合计「补领数量」（与导出件的小计行同口径）。

## 5. 没做 / 非目标

- **不做批量打印/批量导出**（用户选了逐张）：一叠连续打印要处理分页与打印机套打，等真有需要再做。
- 不加金额、不盖电子章、不做 PDF 服务端生成：出纸方式是浏览器打印 / 另存 PDF。
- 补料单的「图片」列没有数据源（系统未维护补料图片），留空格供手贴 —— 与既有导出件一致。
- 成品出库单不自动带出纸品图片（工艺单才有图片区）。
