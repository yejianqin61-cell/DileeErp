## 2. What it means

用户刷新时，页面先恢复服务器快照，再从 `latest_seq` 续接同一条 SSE；隔离环境中的真实浏览器已证明该过程中只有一次 `POST /runs`，最后能回到“已完成”。取消也在真实浏览器中落到“已取消”。
降权连接在每次重放和轮询读取前都被检查。没有答案片段的失败仍显示稳定错误。
运行超时、许可、结果大小和观测字段沿用已有边界，且回归测试通过。五用户并发 HTTP 探针现在等待它为验证释放许可而创建的最后一条 run 终态，因此可安全与同账号契约测试串行运行。

## 3. Still open

- 真实浏览器已覆盖刷新与取消；断线、429、409 与撤权仍分别只有 reducer/组件、HTTP 或 transport 证据，尚未组成同一套浏览器登录流程。
- 真实模型端点和代表性订单需要在 Phase 6 的预发布环境中验证。缺少它时，不能证明外部提供商下的耗时与重连体验。
- 本机开发库尚未应用到当前迁移版本（缺少 Agent 表和订单字段）；本轮改用完整迁移的隔离测试库，开发/预发布部署前仍须执行既有迁移发布流程。
