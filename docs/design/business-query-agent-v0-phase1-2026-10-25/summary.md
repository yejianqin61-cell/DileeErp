## 2. 意味着什么

业务查询 Agent 从三篇设计文档变成了可运行的模块：模型侧只见固定工具目录，数据侧只剩一条
只读连接，权限在每个工具调用前重查。阶段 2 接 DeepSeek 时，编排器、状态机、SSE 与前端都不用动，
只替换 provider 实现——本批留的正是这个接缝。
