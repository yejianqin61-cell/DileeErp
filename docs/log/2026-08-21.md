## 下一条链路设计

- 新增 [BOM -> 采购 -> 来料 QC -> 原料入库 -> 应付来源实现设计](../design/bom-procurement-inbound-qc-payable-chain-implementation-design.md)。
- 决策：以“BOM -> 采购 -> 来料 QC -> 原料入库 -> 应付来源”命名并限定为一个纵向实现切片；范围止于财务接收应付来源草稿。原因是该链路依赖已完成的销售单、订单号和 BOM 来源能力，同时为后续生产领料和财务付款提供可追溯的原料事实。
- 文档固定了该纵向切片的边界、核心对象、状态动作、REST 接口、事务/幂等、影响预览、告警和测试门槛；不提前锁死 BOM/QC 可扩展明细，也不实现财务付款核销。已与仓库规则对齐：合格和条件接收数量经仓库明确确认后均可入可用原料库存，并以实际可计价入库数量生成应付来源。
- 未决项：条件接收的具体处置权限、供应商结算/税费规则、退供应商的单据字段和财务应付合并规则，待对应负责人确认后补充到模块设计。
