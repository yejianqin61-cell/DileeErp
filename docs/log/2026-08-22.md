### task 03：员工日报、计价与生产薪资来源 API

- 新增员工计件/计时日报 REST API 及只读生产薪资来源查询；
- 按员工、工序和日报日期取得有效计价，保存单价与金额快照，使用 Decimal 计算；
- 计时日报同时保存件数和分钟，件数参与差异核对但不参与金额；
- 员工停用/离职、无效计价、非法件数/时长、无原因覆盖单价均在服务端拒绝；
- 员工日报变更在事务内更新同日差异事实；API build 通过，数据库回归列入 task 07。
