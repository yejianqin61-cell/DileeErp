## 4. 顺带修的两个真 bug

`npm run db:seed:mock` 在本轮之前是**跑不通**的（本地库因此没有 MOCK 基线数据）：

1. `bomItem` 缺 `materialName`（schema 是必填）→ P2003 类错误直接中断；
2. `employee.employeeType: "worker"` 违反 DB 约束 `employees_employee_type_check`（只允许 `workshop` / `non_workshop`）。

两处都改在脚本里，改完幂等可重跑，输出 `MOCK-ORD-001/002`、`MOCK-PROD-001/002`。**这两处不是本轮新引入的，是脚本与 schema 早就漂了。**

## 5. 一次「基线把我自己写错了」的记录

第一次跑全量，4 条 entry 用例红。逐条追事件后确认**是我的期望值写错了，不是工具坏了**：
