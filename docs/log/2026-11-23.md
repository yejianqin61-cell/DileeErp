> 把系统结算方式改下，加入中国银行-人民币账户，还有备用金（招商银行账户）

## 1. 口径确认

本系统的「结算方式」由「方式文本 + 结算账户」拼成。用户给的是**账户名**，因此落在
`dictionary_types.key='settlement_account'` 的结算账户字典上，而不是银行账户池 `banks`
（后者建户要开户行/账号/账户名/币种，用户没有给，不能擅造主数据）。

## 3. 生产数据补齐（人工步骤）

按仓库红线没有新增 migration、没有直接写生产库。已有库部署后需二选一：

1. 打开 **财务 → 结算方式**，点「补齐缺失的内置账户」（只补完全缺失项，不复活停用项）；
2. 或在部署环境执行一次 `npm run db:seed --workspace=@dilee/api`（seed 是 upsert，幂等）。

新库 / 跑过 seed 的库会直接有 4 项，收支流水表单的「结算账户」下拉立刻可选。
