## 领料单表单补齐打印件上的四个数量（配料 / 已领 / 本次 / 余下）

用户原话：

> 领料单这边，系统中的领料单表单还要多一些字段，和领料单导出件保持一致。
> 增加配料数量、已领数量、本次领料量和余下数量

### 1. 查清后的真相：打印件早有这四列，缺的是表单；而且两边数字对不上

| 打印件（Excel 领料单） | 全屏编辑页（改前） | 生产单面板草稿表（改前） |
|---|---|---|
| 配料数量 | 核定用量 | BOM 核定用量 |
| 已领数量 | 生产领用数量（**含**本单） | 生产已领累计（**含**本单） |
| 本次领料量 | 领料数量 | 本次领料数量 |
| 余下数量 | 生产未领用数量（**不含**本单） | 生产未领用（**不含**本单） |

打印件口径：已领 = 净领料 **扣掉本单自己**；余下 = 配料 − 已领 − **本次**。
页面口径：生产领用数量 = 已领 **+** 本次；生产未领用 = 配料 − 已领（**没减**本次）。
→ 同一格差一个「本次领料量」，车间拿纸核对系统只要本次不是 0 就对不上。
这与上一轮采购单导出「纸面与页面各算一套」是同一类根因，所以这次把口径收到一处。

### 2. 口径只写一次

新增 `apps/api/src/modules/production/material-slip-quantity.ts`：

- `issuedBeforeQuantity(netIssued, ownQuantity, ownPosted)`：草稿不扣本单、已过账扣本单；
- `remainingQuantity(bomQuantity, issuedBefore, current)`：超领返回负数、无配料数量返回 `null`；
- 统一 `toFixed(4)`，挡住 `0.30000000000000004` 这类浮点脏值。

调用方：`material-slip-export.service.ts`（打印件）与 `raw-material-movements.service.ts` 的
`previewLines()`（页面预估）。`issue-preview` 每行新增 `material_quantity / issued_quantity /
current_quantity / remaining_quantity` 四个字段，原有字段全部保留（提交/过账/退料预览共用该函数）。

### 3. 页面改动

- 全屏编辑页（领料单 14 列 / 补料单 10 列）：
  `物料 / 物料代码 / 型号 / 颜色 / 单位 / 配料数量 · 已领数量 · 本次领料量 · 余下数量 / 当前库存量 /
  采购入库数量 / 采购未入库数量 / 备注 / 操作`。
  删掉「生产领用数量」「生产未领用数量」（就是已领+本次、余下+本次，重复且名字对不上打印件）；
  新增「单位」列（打印件有单位，四个数量没单位容易读错）；余下为负标红；表格 min-width 1180→1260。
- 生产单面板草稿表：`物料 / 配料数量 / 已领数量 / 本次领料量 / 余下数量 / 当前库存 / 风险 / 操作`，

## 销售单材料明细：同类目可填多款（3 款伞头 / 2 款伞布）

用户原话：

> 针对销售单，现在支持材料明细那边可以在现有基础上自行添加类目。比如我这一单有3款伞头，
> 2款伞布。就支持自行添加类目来填写。同时，销售单的导出件也要同步跟上

### 1. 先查清哪一半已经有了

2026-10-08 的「其它」区已经支持**自由类目**（自己起名 + 内容 + 物料引用 + 导出）。
真正缺的是**同一固定类目填多款**：18 个类目每格只有一格输入框，
3 款伞头只能挤进「其它」区、印在最下面，还要手打三次「伞头」（打错一个字纸上就多一个类目）。

老板在 A/B 里选了 A：固定类目下点「再加一款」，同类目可多行；导出时同类目连在一起印。

### 2. 改动

- **数据**：`sales_order_material_extras` 加可空 `spec_key`（18 个类目键之一；空 = 原有「其它」行）。
  迁移 `20261029200000_sales_order_material_extra_spec_key`，schema 同步。
- **服务层**：`normalizeMaterialExtras` 认 `spec_key`；类目名由服务端按一份清单（`sales-material-labels.ts`）
  填，**不采用请求里的 label**；未知键 422 `MATERIAL_EXTRA_SPEC_KEY_UNSUPPORTED`；
  返单预览 / 普通复制 / 版本快照都带上 `spec_key`。
- **导出件**：材料区按「18 类目 → 每类目自己那一格 + 它的追加款」组装，自由「其它」行仍印在最后；
  图片候选排序跟着类目走（类目序号 + 0.5）。
- **前端**：每格下面「再加一款」（虚线框、只填内容与引用）；「其它」块只渲染自由行；
  回填两种键名形状都认；报错带类目名。
- **样例**：`docs/samples/工艺单-样例.xlsx` + `工艺单-样例-预览.png`（3 伞头 / 2 伞布 / 1 个自由类目）。

### 3. 测试

- API `sales-order-material-extras.test.cjs` +6（归一 / 落库 / 快照 / 返单 / 导出归位 / 图片候选排序 / 迁移）。
- web `sales-order-spec.test.mjs` +2、`sales-order-material-extra.test.tsx` +2。
