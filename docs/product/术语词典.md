# 迪礼 ERP 领域术语词典

## 使用规则

- 本词典是跨模块的统一语言。代码、API、数据库和文档优先使用“规范名称”。
- 同一概念不得在不同模块使用不同名称；业务负责人确认新词后再补充本词典。
- 尚未确认的术语标记为“待确认”，不得据此固化复杂业务规则。

## 核心业务术语

| 规范名称 | English key | 定义 | 备注 |
| --- | --- | --- | --- |
| 订单 | order | 迪礼 ERP 内串联生产、采购、仓库、质量和财务的根业务对象 | V1.0 由操作员直接创建生产订单 |
| 订单号 | order_no | 订单对外可读的业务编号 | 与数据库 `id` 分离，是全流程追溯主线 |
| 外部合同号 | external_contract_no | 客户或外部系统提供的合同参考号 | 可选，不作为系统主键 |
| 关联单据 | related_document | 通过订单号或业务外键与订单关联的采购、生产、检验、出入库、收付款记录 | 单据编号规则待确认 |
| 状态 | status | 实体当前所处的业务阶段 | 由统一状态机约束 |
| 状态流转 | status_transition | 实体从一个状态变为另一个状态的动作 | V1.0 以人工维护为主 |
| 物料 | material | 被采购、库存、领用或用于生产的原料及相关物品 | 物料范围待采购/仓库确认 |
| 成品 | finished_good | 生产完成并可入库、出货的产品 | 具体产品结构待生产确认 |
| 原料 | raw_material | 用于生产的投入物料 | 独立库存分类 |
| 退料 | returned_material | 从生产现场退回仓库的物料 | 独立库存分类 |
| 不良品 | defective_item | 检验不合格、不可直接进入可用库存的物品 | 独立库存分类 |
| 生产单 | production_order | 描述订单生产任务及其工序进度的业务单据 | 与订单关联 |
| 工序 | operation | 生产任务中的一个加工或作业步骤 | 名称、顺序和进度字段待车间确认 |
| 采购单 | purchase_order | 向供应商采购物料的业务单据 | 与订单和供应商关联 |
| 检验 | inspection | 对来料或成品进行质量判断的记录 | 允许部分合格 |
| 合格数量 | accepted_quantity | 检验后进入可用库存的数量 | 与不合格数量之和不超过送检数量 |
| 不合格数量 | rejected_quantity | 检验后进入不良品库存的数量 | 与合格数量可并存 |
| 入库 | stock_in | 将合格物料或成品增加到相应库存的动作/单据 | 原料、成品分开管理 |
| 出库 | stock_out | 将库存物品发出、领用或转出的动作/单据 | 具体业务类型待仓库确认 |
| 盘点 | stocktaking | 以实际清点数量核对账面库存的业务过程 | V1.0 手工盘点 |
| 应收 | receivable | 迪礼应从客户收取的业务款项 | 不等同会计总账 |
| 应付 | payable | 迪礼应向供应商或其他对象支付的业务款项 | 不等同会计总账 |
| 收款 | receipt | 客户向迪礼支付应收款的记录 | 支持多币种 |
| 付款 | payment | 迪礼支付应付款的记录 | 支持多币种 |
| 客户池 | customer_pool | 销售管理中维护客户基础资料的范围 | V1.0 不含询盘报价流程 |
| 供应商 | supplier | 提供物料或服务的外部合作方 | 采购基础资料 |
| 员工 | employee | 迪礼内部人员档案对象 | 界面统一使用“员工” |
| 考勤 | attendance | 员工出勤记录 | 不自动计薪 |
| 绩效 | performance | 员工绩效记录 | 不自动计薪 |
| 薪资台账 | payroll_ledger | 按周期人工录入/确认的薪资记录 | 不建设自动计薪 |

## 系统术语

| 规范名称 | English key | 定义 |
| --- | --- | --- |
| 基础资料 | master_data | 客户、供应商、员工、物料等可复用资料 |
| 字典 | dictionary | 币种、计量单位、状态等可配置枚举数据 |
| 逻辑删除 | soft_delete | 保留记录、标记删除、常规查询隐藏 |
| 可追溯更正 | traceable_correction | 在允许范围内纠正业务数据，同时保留原始事实、变更原因、前后值、执行人和时间，并联动重算派生数据或产生复核提示 |
| 影响预览 | impact_preview | 保存可能影响上下游数据的变更前，系统向操作员展示受影响单据、派生数据变化、告警和需人工复核风险的结果 |
| 差异/复核提示 | discrepancy_review_warning | 上游编辑不能直接改写已确认下游事实时，提示来源与当前数据不一致，要求对应业务人员复核或创建调整记录 |
| 审计字段 | audit_fields | `created_at`、`updated_at`、`created_by`、`updated_by` |
| 附件 | attachment | 统一的文件元数据与业务实体关联模型 |
| 操作员 | operator | 使用系统完成业务录入和查询的人员 |
| 管理员 | administrator | 维护账号、权限和系统字典的角色 |
| 业务模块负责人 | module_owner | 负责模块流程定义和验收的业务经理 |

## 明确不采用的近义词

- “客户订单”“销售订单”“生产订单”在当前 V1.0 语境中不得混用；根对象统一称“订单”，直接创建的业务单据称“生产单”。
- “删除”默认指逻辑删除；需要物理清理时必须明确写“物理删除”，且 V1.0 禁止业务数据物理删除。
- “产品 SKU”“通用 BOM”“配方版本”不是当前默认概念，待生产和物控访谈确认后再加入。

## 待确认术语

生产工序、订单物料清单、库存成本、批次/批号、单位换算、采购分批到货、单据编号等术语和定义，见 [0818 初定义待确认事项](../memo/0818初定义待确认事项.md)。
